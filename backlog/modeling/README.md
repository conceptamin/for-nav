# 모델링 백로그

이 폴더에는 사용자가 추후 작성할 모델링 phase 문서를 둔다. 현재 확정된 phase 문서는 없다.

- 담당 범위: 데이터·특성·예측·온라인 보정·평가
- 구현 경로: `agents/, training/`
- 작업 규칙: [영역 지침](../../modeling/AGENTS.md)
- 운영 방식: [하네스](../../docs/HARNESS.md)
- 참고 초안: [modeling.json](../modeling.json)

파일명은 `phase-01.md`, `phase-02.md` 등을 사용할 수 있다. 각 문서에 목표·작업 체크리스트·선행 의존성·완료 조건·검증 명령과 결과를 기록한다. 번호와 진행 상태는 다른 영역과 독립적이다.

다른 영역의 선행 작업은 해당 phase 문서의 상대 경로와 필요한 산출물을 연결한다. 구현 및 완료 상태는 이 영역의 phase 문서에서만 관리한다.
