# 화면을 그리는 규칙

`src/styles.css` 한 파일과 `src/components/`의 공통 조각으로 화면을 그릴 때 지키는 규칙이다. 지금 코드에 이미 들어 있는 스타일을 명문화한 것이므로, 여기에 없는 모양을 새로 그릴 때는 이 문서를 먼저 고친다. 무엇을 보여 주는지는 `README.md`, 코드 규칙은 `CLAUDE.md`가 정한다.

## 두 영역의 원칙

| 영역 | 경로 | 기준 | 원칙 |
|---|---|---|---|
| 근로자 | `/` ~ `/my`, `/guide` | 모바일 우선. 360px 폭에서 설계하고 `.w-shell`은 480px까지만 넓어진다 | **한 손으로, 큰 글씨로, 글을 다 읽지 못해도 누를 수 있게.** 화면 하나에 묻는 것은 하나다. 119는 언제나 한 번 누르면 걸린다 |
| 센터 | `/center*` | PC 우선. `.c-main`은 1280px, 900px 이하에서 한 열로 접힌다 | **밀도와 한눈에 보이는 상태.** 표·칩·KPI로 많은 사례를 비교한다. 담당자는 한국어를 읽는다 |
| 응급 | `/emergency` | 근로자 영역이지만 따로 취급 | 빨간 전면 히어로 하나와 전화 버튼 하나. 다른 정보는 그 아래로 내린다. 하단 119 띠는 이 화면에서만 숨긴다(버튼이 중복되므로) |

근로자 화면의 공통 틀은 `WorkerLayout`(헤더 + 언어 선택 + 하단 119 띠), 센터 화면은 `CenterLayout`(상단 브랜드 + 탭 메뉴)이다. 화면 컴포넌트는 틀을 다시 그리지 않는다.

## 토큰

색·둥글기·그림자·글자 크기는 `:root`의 CSS 변수로만 정한다. 새 색이 필요하면 **토큰을 먼저 더하고** 그 토큰을 쓴다. 클래스 안에 16진수 색을 직접 쓰지 않는다.

| 토큰 | 값 | 의미 |
|---|---|---|
| `--ink` | `#12232e` | 본문 글자 |
| `--ink-2` | `#4a5a66` | 보조 글자(설명, 레이블) |
| `--ink-3` | `#74838e` | 흐린 글자(각주, 비활성) |
| `--line` | `#d9e1e6` | 테두리, 구분선 |
| `--bg` | `#f3f6f8` | 화면 배경 |
| `--card` | `#ffffff` | 카드·입력란·칩의 배경 |
| `--brand` | `#0f5b78` | 주 동작, 선택됨, 링크 |
| `--brand-2` | `#e3f0f5` | 선택된 칩 배경, 정보 안내 배경 |
| `--ok` / `--ok-bg` | `#1f7a4d` / `#e5f4ec` | 완료, 해당됨 |
| `--warn` / `--warn-bg` | `#9a5b00` / `#fff3dc` | 주의, 제도·운영 시간 안내, 보통 긴급도, 진행 중 |
| `--danger` / `--danger-2` / `--danger-bg` | `#c4231b` / `#a11a13` / `#fde8e6` | 119·응급(근로자), 높은 긴급도(센터) |
| `--radius` | `14px` | 카드. 버튼·칩·안내는 12px, 응급 전화 버튼은 16px |
| `--shadow` | 2겹 그림자 | 카드와 하단 119 띠. 그 외에는 쓰지 않는다 |

### 색의 의미

- **근로자 화면에서 빨강은 119와 응급에만 쓴다.** "심해지면 119" 안내(`Worse119`), 응급 히어로, 하단 띠, 위험 버튼(삭제)만 빨강이다. 오류 문구는 빨강 안내(`notice.danger`)를 쓰되 119 안내보다 눈에 띄게 만들지 않는다.
- 센터 화면에서는 긴급도 "높음" 칩이 빨강이다. 담당자에게는 자연스러운 신호이고, 센터 화면에는 119 버튼이 없어 혼동이 없다.
- 브랜드색은 선택됨과 주 동작이다. 장식으로 쓰지 않는다.
- `warn`은 "확인이 필요하다"는 뜻이다. 제도 안내, 운영 시간 외, 진행 중 상태가 여기에 속한다.
- `ok`는 끝났거나 해당된다는 뜻이다.

### 토큰이 없는 색(정리 대상, backlog 04)

지금 `styles.css`에는 토큰 밖 색이 남아 있다. 새 코드에서는 쓰지 않고, 기존 자리는 backlog 04에서 토큰으로 바꾼다.

| 색 | 쓰인 곳 | 바꿀 토큰 |
|---|---|---|
| `#fff` 배경·글자 | 칩, 입력란, 버튼, 카드류 전반 | `--card`(배경), 새 토큰 `--on-brand`(어두운 배경 위 글자) |
| `#f0a500` | 포커스 윤곽, `pill.live`, 실제 전송 행 왼쪽 띠 | 새 토큰 `--accent` |
| `#5c3700`, `#0b3e52`, `#134d31` | `notice` 글자색 | `--warn`, `--brand`, `--ok`의 어두운 변형 토큰 |
| `#dceeff` / `#0b4f8a` | `pill.new` | 새 토큰 `--info` / `--info-bg` |
| `#edf1f3`, `#eef2f5`, `#f7f9fa`, `#f5f9fb`, `#fff8e1` | 센터 배경·표 줄무늬 | `--bg` 계열 토큰 |

## 글자

- 글꼴은 **시스템 글꼴**이다. `font-family`에 적힌 Pretendard·Noto Sans KR은 기기에 있을 때만 쓰이고, 웹폰트를 내려받지 않는다. 발표장 네트워크에 기대지 않고, 베트남어 성조 글리프도 시스템 글꼴이 안전하다.
- 기본 크기 1rem(16px), 줄 간격 1.5. 아래 단계만 쓴다.

| 단계 | 크기 | 쓰는 곳 |
|---|---|---|
| 한국어 크게 | 1.6rem / 1.45rem / 1.2rem | 진료과 이름(`.dept .ko`), 접수 창구 문장(`.ko-big`), 3언어 줄의 한국어(`.line .ko`). 창구 직원이 휴대폰 화면을 건너 읽는 크기다 |
| 응급 | 1.7rem / 1.5rem | 응급 전화 버튼, 응급 히어로 제목 |
| 제목 | 1.45rem / 1.15rem / 1rem | h1 / h2 / h3. 화면에 h1은 하나다 |
| 본문 | 1rem | 본문, 버튼, 칩(0.98rem) |
| 보조 | 0.92rem / 0.85rem | 안내 상자, 발음·모국어 줄, 작은 설명 |
| 최소 | 0.82rem | 각주(`.footer-note`), 센터 칩. 이보다 작게 쓰지 않는다. 예외는 헤더의 "Demo" 배지(0.72rem) 하나다 |
| 센터 숫자 | 1.8rem | KPI 수치 |

- 한국어로 고정된 글(접수 창구 문장, 전화 스크립트, 센터 화면)에는 `lang="ko"`를 단다. 근로자가 고른 언어의 글에는 문서 언어를 따르게 둔다.

## 크기

누르는 것은 손가락 기준이다.

| 요소 | 최소 높이 |
|---|---|
| 응급 전화 버튼(`.em-call`) | 76px |
| 홈 메뉴 항목(`.menu a`) | 72px |
| 큰 버튼(`.btn.big`) | 60px |
| 칩(`.chip`), 하단 119 띠 | 52px |
| 버튼(`.btn`), 입력란, 세그먼트 칩 | 48px |
| 토글(`.toggle button`) | 44px |
| 센터 필터·헤더 선택 | 36~38px(PC, 마우스 기준) |

- 근로자 화면에서 누르는 것은 48px 아래로 내리지 않는다.
- 간격은 8px 단위다. 카드 안 여백 16px, 카드 사이 12px, 요소 사이 8px.
- 하단 119 띠가 내용을 가리지 않도록 `.w-main`은 아래 여백을 띠 높이만큼 둔다. 안전 영역(`env(safe-area-inset-bottom)`)은 띠가 처리한다.

## 컴포넌트

공통 조각은 `styles.css`의 클래스와 `components/common.tsx`의 React 조각이다. 아래 표에 없는 것을 새로 만들기 전에 표의 것으로 그릴 수 없는지 먼저 본다.

### 근로자 화면

| 클래스·조각 | 무엇 | 언제 쓴다 | 쓰지 않는 때 |
|---|---|---|---|
| `.card` | 흰 배경, 둥글기, 그림자, 여백 16 | 화면의 내용 묶음 하나 | 카드 안에 카드를 넣지 않는다 |
| `.btn` + `secondary` / `ghost` / `danger` / `block` / `big` | 버튼. 기본은 브랜드색 채움 | 주 동작은 화면에 하나(`.block`으로 가로 꽉). 되돌아가기는 `ghost`, 보조는 `secondary`, 삭제는 `danger` | 링크처럼 보이는 글자 버튼을 만들지 않는다 |

| `.ko-big`, `.line` (`.ko` + `.pron` + `.native`) | 3언어 줄. 한국어 크게, 아래 발음, 그 아래 모국어 | 접수 창구 문장, 전화 스크립트 | 한국어 사용자에게는 `.pron`·`.native`를 그리지 않는다(`pron()`이 빈 문자열) |

## 화면 유형별 규칙

| 유형 | 화면 | 구성 순서 |
|---|---|---|
| 입력 | S-02, S-03, S-05, S-11 항목 선택, S-12 | h1 → (단계 점) → 질문 하나와 칩·입력란 → 안내 상자 → 아래에 되돌아가기(ghost) + 다음(block) |
| 결과 | S-07, S-08, S-09, S-10 | h1 → 핵심 결과를 크게(진료과·경로·한국어 문장) → 다음 행동 버튼(지도·전화·접수) → `Worse119` → `PolicyDisclaimer`(제도 정보가 있을 때) |
| 응급 | S-06 | `.em-hero`(제목·이유) + `.em-call` → 응급실 지도 → 그 아래 홈으로 돌아가는 ghost 버튼 |
| 리포트 | S-11 | 언어 토글 → `.report-row` 목록 → 저장·삭제 |
| 센터 목록 | C-01 | KPI 4개 → 필터 → 표. 새 사례는 맨 위 |
| 센터 상세 | C-02 | 긴급도·상태 칩 → 2열(요약·연락 / 원문·상태 변경) |
| 센터 통계 | C-03 | 기간·구군 필터 → KPI → 막대·도넛 |

- 응급으로 가는 길은 어느 화면에서도 두 번 이상 누르지 않는다. 하단 띠 한 번, 응급 화면에서는 전화 버튼 한 번.
- 결과 화면은 스크롤 없이 첫 화면에 핵심 결과와 첫 행동 버튼이 보여야 한다(360×640 기준).
- 입력 화면에서 화면이 바뀌면 맨 위로 올린다(`WorkerLayout`이 처리).

## 로딩과 실패를 그리는 법

`README.md` "비동기 UX 규칙"의 시각 표현이다.

| 상황 | 그리는 법 |
|---|---|
| 서버 응답을 기다린다 | 누른 버튼을 `disabled`로. 스피너·스켈레톤·진행 막대를 만들지 않는다 |
| 조용히 대체했다 | 결과 아래 `notice.info` 한 줄. 결과를 가리거나 색을 바꾸지 않는다 |
| 센터 전송·상태 변경이 실패했다 | `notice.danger` 문구 + 바로 옆 "다시 시도" `btn secondary`. 입력값은 그대로 |
| 센터가 서버와 끊겼다 | `.c-header` 아래 가로 띠(`warn` 배경) "서버 연결 안 됨 · 마지막 갱신 HH:MM". 표는 마지막 목록 그대로 |
| 비어 있다 | 카드 안 `.muted` 한 줄("아직 접수된 사례가 없습니다"). 그림·일러스트를 넣지 않는다 |

## 접근성

- **색만으로 뜻을 전하지 않는다.** 선택됨은 ✓ + 테두리 + 굵기, 긴급도·상태는 칩 글자, 응급은 글과 전화 아이콘.
- 고르는 버튼은 `button` + `aria-pressed`. `div`에 클릭을 달지 않는다.
- 아이콘은 이모지이고 전부 `aria-hidden`이다. **뜻은 항상 옆 글자가 전한다.** 기기마다 모양이 다른 것은 감수한다. SVG 아이콘 세트로 바꾸는 것은 별도 항목이다.
- 입력란에는 보이는 `label`을 둔다. 헤더의 언어 선택처럼 레이블을 보일 자리가 없을 때만 `aria-label`.
- 포커스 윤곽(`:focus-visible`, 3px)은 끄지 않는다.
- 장식용 요소(단계 점, 막대 트랙)는 `aria-hidden`이고 같은 정보를 글로 둔다.
- 한국어 고정 글에 `lang="ko"`, 집계 그림에 `role="img"` + `aria-label`.
- 대비는 본문 `--ink`/`--card` 기준으로 WCAG AA 이상을 지킨다. 새 토큰을 더할 때 글자색은 배경 위 4.5:1을 확인한다.

## 하지 않는 것

- UI 라이브러리, CSS 모듈, CSS-in-JS, Tailwind. `styles.css` 한 파일과 클래스 이름으로 끝낸다.
- 다크 모드. `prefers-color-scheme`을 보지 않는다.
- 애니메이션·전환 효과. 상태 변화는 즉시 바뀐다.
- 토큰 밖 색상 하드코딩, 임의 글자 크기, 8px 단위 밖 간격.
- 새 인라인 `style`. 지금 있는 것(버튼 사이 `marginTop` 몇 곳)은 간격만이고 색은 없다. 더 늘리지 않고, 반복되면 수식 클래스로 옮긴다.
- 웹폰트 내려받기, 외부 아이콘 CDN.
- 스피너·스켈레톤·토스트·모달. 확인이 필요하면 `window.confirm`(센터 데모 초기화처럼) 하나로 끝낸다.
- 근로자 화면에서 가로 스크롤, 고정 폭 표, 호버에만 나타나는 정보.

## 새 스타일을 더하는 절차

1. 위 컴포넌트 표의 것으로 그릴 수 있는지 먼저 본다. 변형이 필요하면 기존 클래스에 수식 클래스(`.btn.big`처럼)를 더한다.
2. 새 색·크기가 필요하면 `:root` 토큰을 먼저 더하고 이 문서의 토큰 표에 적는다.
3. 클래스는 `styles.css`의 해당 섹션 주석(`/* ---------- 공통 요소 ---------- */` 같은) 아래에 둔다. 근로자 전용은 `w-`, 센터 전용은 `c-` 접두, 양쪽 공통은 접두 없이.
4. 이 문서의 컴포넌트 표나 화면 유형 표에 한 줄을 더한다. 문서에 없는 모양은 다음 사람이 다시 만들게 된다.
5. 360px 폭(근로자) 또는 1280px·900px 아래(센터)에서 직접 보고, en·vi·ko 세 언어로 글이 넘치지 않는지 확인한다. 베트남어가 가장 길다.
