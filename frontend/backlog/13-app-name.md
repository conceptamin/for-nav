# 13. 앱 이름 통일

상태: 완료(18에 합침)
의존: 없음

## 목표
앱 이름이 화면마다 다르다(2026-10-29 프론트 피드백 1번 "울산 의료 네비게이터 → 명칭 이대로?"). 팀이 이름을 하나로 정하면 화면에 보이는 이름을 전부 그 이름으로 바꾼다. 문서·패키지 이름 같은 프로젝트 이름은 바꾸지 않는다.

지금 보이는 이름:

| 자리 | 지금 | 파일 |
|---|---|---|
| 브라우저 탭 제목 | 울산 외국인 의료 내비게이터 | `index.html` |
| 앱 바(언어를 고르기 전, S-01) | 울산 외국인 의료 내비게이터 | `WorkerLayout.tsx`의 고정 문자열 |
| 앱 바(언어를 고른 뒤, `/`·`/home`), 로그인 화면 h1 | ko `울산 의료 내비게이터` / en `Ulsan Medical Navigator` / vi `Hướng dẫn y tế Ulsan`(직역 "울산 의료 안내") | i18n `appName` |
| 로그인 화면 한 줄 | ko `울산 외국인 근로자를 위한 병원 이용 안내` 등 | i18n `appTag` |
| 센터 헤더 | 울산 외국인주민·근로자 통합지원센터 · 의료지원(기관 이름, 앱 이름 아님) | `Center.tsx` |

## 결정이 필요한 것
팀이 정한다. 각 항목에 권장안을 적었다.

1. **한국어 이름.** `울산 의료 내비게이터`(짧다, 지금 ko) / `울산 외국인 의료 내비게이터`(PRD 문서 제목, 지금 탭·언어 전 앱 바). 권장: 화면은 짧은 이름. 앱 바(48px)에 언어 선택과 같이 들어가야 하고, "외국인 근로자를 위한"은 `appTag` 한 줄이 이미 말한다. 긴 이름은 문서의 프로젝트 이름으로 남긴다.
2. **표기.** `내비게이터`(표준 표기, 지금 코드) / `네비게이터`(피드백의 표기, 입말). 권장: `내비게이터`. 공공기관 앞에 보일 이름이다.
3. **영어·베트남어.** en `Ulsan Medical Navigator`는 유지. vi `Hướng dẫn y tế Ulsan`은 "안내"라 "내비게이터"와 뜻이 다르다. 원어민 검수에서 함께 정한다(후보를 여기서 만들지 않는다).
4. **로고 워드마크를 쓸지**는 14번에서 정한다. 이름이 정해져야 워드마크 폭이 나온다.

## 범위
- 하는 것(결정 뒤)
  - `index.html` `<title>`, `WorkerLayout.tsx`의 언어 전 고정 문자열, i18n `appName`(en·vi·ko)을 정한 이름으로. 세 곳이 같은 이름을 내게 한다
  - `appTag`는 이름이 바뀌어 뜻이 겹치면 고친다(예: 긴 이름을 고르면 "외국인 근로자를 위한"이 두 번 보인다)
  - `README.md` 화면 구성 표·`design.md` 앱 바 설명에 이름이 들어 있으면 같이 고친다
- 하지 않는 것
  - `package.json` `name`, 폴더 이름, 문서 제목(`README.md` 첫 줄, 루트 `CLAUDE.md`), PRD 파일 이름. 프로젝트 이름은 화면 이름과 별개다
  - 센터 헤더의 기관 이름. 앱 이름이 아니다
  - 로고·파비콘(14번)

## 화면·파일
- 화면: 브라우저 탭, S-01 `/`·S-04 `/home` 앱 바, S-03 `/signup` 로고 화면 h1
- 수정: `index.html`, `src/components/WorkerLayout.tsx`, `src/i18n/{en,vi,ko}.ts`, 필요하면 `README.md`·`design.md`
- 새 문구 키: 없음(`appName`·`appTag` 값만 바뀐다)

## 완료 기준
- [ ] 팀이 1~3번을 정했고 그 결정을 `## 결과`에 적었다
- [ ] `npm run build` 통과
- [ ] 브라우저 탭 제목, 언어를 고르기 전 앱 바, 언어를 고른 뒤 앱 바(`/`·`/home`), 로그인 화면 h1이 같은 이름이다(ko)
- [ ] 360px en·vi·ko에서 `/home` 앱 바의 이름이 언어 선택 옆에서 말줄임 없이 한 줄이다
- [ ] `grep -rn "내비게이터\|네비게이터\|Navigator" index.html src`가 정한 표기만 낸다

## 결과
2026-10-30 팀이 이름을 `for nav`로 정했고, 이 항목은 18(팀 키 컬러·로고·앱 이름)에 합쳐 구현했다. 1번: 화면 이름은 모든 언어에서 `for nav`(번역하지 않는 고유 이름). 2번: 화면에서 `내비게이터` 표기가 빠져 결정할 일이 없어졌다. 3번: en·vi도 `for nav`. 4번: 워드마크 그림은 쓰지 않는다. 결과 기록은 `18-brand-teal.md`에 있다.

## 메모
- 2026-10-29 프론트 피드백 1번에서 왔다. 4번(데모 표시)은 11, 2번(홈·개인 화면)은 12, 3번(로고)은 14다
- 베트남어 이름을 바꾸면 원어민 검수가 필요하다
- 앱 바는 `.title`이 한 줄 말줄임이라 긴 이름을 고르면 베트남어에서 잘릴 수 있다. 고르기 전에 360px에서 세 언어를 본다
