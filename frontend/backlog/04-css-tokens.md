# 04. 토큰 밖 색상 정리

상태: 완료
의존: 없음 (`styles.css`만 고치므로 01~03과 겹치지 않는다. 번호 순서를 지키되, 01~03이 막혀 있으면 먼저 해도 된다)

## 목표
`design.md` "토큰이 없는 색(정리 대상)" 표의 색을 전부 `:root` 토큰으로 바꿔, 클래스 안에 16진수 색이 남지 않게 한다. 화면 모양은 바꾸지 않는다. 목적은 "새 색은 토큰부터"라는 규칙을 기존 코드가 먼저 지키게 하는 것이다.

## 범위
- 하는 것
  - `:root`에 토큰 추가: `--on-brand`(어두운 배경 위 글자, `#fff`), `--accent`(`#f0a500`: 포커스 윤곽·`pill.live`·실제 전송 행 띠), `--info`/`--info-bg`(`pill.new`), `--warn-ink`/`--brand-ink`/`--ok-ink`(`notice` 글자색 `#5c3700`·`#0b3e52`·`#134d31`), `--bg-2`/`--bg-3`(센터 배경·표 줄무늬 `#eef2f5`·`#f7f9fa`·`#f5f9fb`·`#edf1f3`은 가까운 둘로 합친다), `--live-bg`(`#fff8e1`)
  - `:root` 밖의 모든 16진수 색을 토큰으로 치환. `#fff` 배경은 `--card`, `#fff` 글자는 `--on-brand`
  - `design.md` 토큰 표에 새 토큰을 적고 "토큰이 없는 색(정리 대상)" 절을 지운다
  - 센터 배경 네 색을 둘로 합치면서 생기는 미세한 차이는 허용한다(그 외는 바이트 단위로 같은 색)
- 하지 않는 것
  - 새 모양·간격·글자 크기, 클래스 이름 변경, 다크 모드
  - `font-family` 변경(시스템 글꼴 동작은 지금 그대로다)
  - 컴포넌트(`.tsx`) 수정. 인라인 `style`은 `Intake.tsx`·`Report.tsx`의 간격(`marginTop`·`marginBottom`) 몇 곳뿐이고 색이 아니므로 그대로 둔다

- 수정: `src/styles.css`, `design.md`

- [x] `awk '/^:root/,/^}/{next} {print NR": "$0}' src/styles.css | grep -E '#[0-9a-fA-F]{3,6}([^0-9a-fA-F]|$)'`의 출력이 비어 있다(`:root` 밖에 16진수 색이 없다). macOS 기본 awk는 정규식의 `\b`를 모르므로 원래 적었던 awk 한 줄은 색이 있어도 빈 출력을 낸다. 그래서 grep으로 바꿨다

남은 것
- `pages/center/Center.tsx`의 도넛 색 `PIE_COLORS` 세 개는 컴포넌트 안 16진수 색이다. 이 항목은 `.tsx`를 고치지 않으므로 남겼다. 클레이모피즘 적용(06)이나 별도 항목에서 토큰(`var(--brand)` 등)으로 바꾼다
- 헤더 데모 배지(`.badge`)와 홈 첫 메뉴 아이콘 칸(`.menu a.primary .ico`)의 반투명 흰색 `rgb(255 255 255 / 20%)`·`18%`는 16진수가 아니라 이번 기준에 걸리지 않는다. 06이 그림자 재료와 함께 정리한다
