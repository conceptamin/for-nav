# 14. 로고 마크와 파비콘

상태: 보류(로고 출처를 정하면 대기로 바꾼다)
의존: 없음(마크만). 이름 옆에 워드마크까지 넣으려면 13이 먼저다

## 목표
앱에 로고가 없다(2026-10-29 프론트 피드백 3번 "우리 앱 로고 필요하지 않을까요?"). 브라우저 탭은 기본 아이콘이고(`<link rel="icon">` 없음, `public/` 폴더 없음), 언어 선택·로그인 화면 가운데는 🏥 이모지, 앱 바는 글자뿐이다. 시연 영상과 발표에서 "이 앱"이라고 가리킬 수 있는 마크 하나를 만들어 파비콘·로고 화면·앱 바에 넣는다. 파일 하나(`SVG`)로 두어 나중에 디자이너 로고로 바꿀 때 그 파일만 갈아 끼우면 되게 한다.

## 결정이 필요한 것
1. **로고 출처.** (a) 디자이너가 만든 로고가 있거나 Figma(conceptamin 파일)에 있다 → SVG로 받아 쓴다. (b) 없다 → 이 항목에서 브랜드색 기반의 간단한 마크를 만든다(시연용, 뒤에 교체). 권장: (b)로 먼저 넣고 (a)가 생기면 파일만 바꾼다.
2. **형태.** 마크(아이콘)만 / 마크 + 워드마크(이름을 그린 글자). 권장: 마크만. 이름은 지금처럼 시스템 글꼴 글자로 둔다("하지 않는 것": 웹폰트 내려받기). 워드마크는 13에서 이름이 정해진 뒤 따로 본다.
3. **모티프**(b일 때). 권장: 브랜드색(`#0f5b78`) 둥근 네모 안에 흰 위치 핀 + 작은 플러스(의료 + 길 안내). **빨간 십자(적십자 표장)와 초록 십자(약국·녹십자 상표)는 쓰지 않는다.** 병원·진단을 연상시키는 그림(청진기·알약)도 피한다. 앱은 진단하지 않는다.
4. **센터 화면에도 넣을지.** 권장: 넣지 않는다. 센터 헤더는 기관 이름이 주인이고, 근로자 앱의 마크가 기관 로고처럼 보이면 안 된다.

## 범위
- 하는 것(결정 뒤)
  - `frontend/public/` 폴더를 만들고 `logo.svg` 하나를 둔다(파비콘도 같은 파일). `README.md` 폴더 구조와 `CLAUDE.md` 폴더 표에 `public/`을 더한다(새 폴더는 이유를 적는다: 빌드 없이 그대로 서빙되는 정적 파일, Vite 기본 `publicDir`)
  - `index.html`: `<link rel="icon" type="image/svg+xml" href="/logo.svg">`. `theme-color`는 지금 그대로(`#0f5b78`)
  - S-01·S-03 로고 화면 `.w-logo .mark`: 🏥 이모지 → `<img src="/logo.svg" width="64" height="64" alt="">`. 크기는 지금 이모지(3rem ≈ 48px)보다 조금 크게 64px
  - 앱 바(`.w-header`): `/`·`/home`에서 앱 이름 왼쪽에 마크 24px(`<img>`, `alt=""`, 오른쪽 간격 8px). ← 가 있는 화면에는 넣지 않는다(왼쪽 자리가 ← 것이다)
  - `styles.css`: `.w-header .logo`(24px, `flex: none`), `.w-logo .mark img`(64px). 새 색 없음
  - `design.md`: 컴포넌트 표 `.w-logo`·`.w-header` 행과 "홈과 내 화면" 홈 표의 앱 바 행("뒤에 로고가 들어올 자리")을 고친다. 로고 색 규칙 한 줄: 마크는 브랜드색과 흰색만 쓴다
- 하지 않는 것
  - PNG 아이콘 세트(`apple-touch-icon`, 192/512px), PWA `manifest`, 스플래시 화면. 웹 데모에 설치 흐름이 없다. SVG 파비콘은 Chrome·Edge·Firefox·Safari 최신에서 보인다
  - 외부 CDN 아이콘, 웹폰트 워드마크("하지 않는 것")
  - 센터 헤더 로고(결정 4를 "넣는다"로 바꾸면 그때 더한다)
  - `.menu .ico`·결과 카드의 이모지 아이콘 교체. 로고와 별개다
