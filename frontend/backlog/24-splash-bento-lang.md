# 24. 첫 실행: 로고 스플래시 + 언어 선택 벤토 그리드

상태: 완료
의존: 없음(20·22·23 위에서 한다. 23은 브랜치를 만들기 전에 병합됐다)

## 목표
2026-10-30 사용자 요청: "처음 앱을 열었을 때 우리 로고가 뜨는 스플래시 화면 만들어줘. 그 후 앱을 처음 사용할 때 뜨는 언어선택 화면을 지금과 같은 대화형 인터페이스 말고 벤토 그리드로 변경해줘." 앱을 열면 팀 로고가 잠깐 보이고, 언어 선택 S-01은 안내원 말풍선 + 대답 말풍선 + 알약 대신 **크기가 다른 타일을 맞물린 격자(벤토 그리드)** 하나로 20개 언어를 모두 한눈에 보인다.

## 범위
- 하는 것
  - **스플래시** (경로 없음. `WorkerLayout`이 화면 대신 그린다)
    - 언제: 근로자 화면(`/`, `/home` 등 `WorkerLayout` 아래 모든 경로)을 **브라우저 세션에서 처음 열 때 한 번**. 같은 탭에서 새로고침하거나 화면을 옮겨도 다시 뜨지 않는다. 새 탭·앱을 다시 열면 또 뜬다. 센터 화면(`/center*`)에는 없다
    - 얼마나: 1.2초 뒤 저절로 사라진다. 화면 아무 곳이나 누르면 바로 넘어간다. 넘어간 뒤에는 원래 열려던 경로가 그대로 보인다(처음 사용자는 S-01, 이미 쓰던 사람은 그 화면)
    - 무엇: 가운데 로고(`/logo.png`, 96px) + 앱 이름 `for nav`. 언어를 아직 모르므로 문구는 앱 이름 하나뿐이다. 앱 바는 없다
    - **하단 119 띠는 스플래시에도 보인다.** 119 버튼은 로딩 상태와 관계없이 보여야 한다(`frontend/CLAUDE.md` "설계에서 바꾸지 않는 것")
    - 애니메이션 없음(나타나고 사라지는 효과 없이 바로 바뀐다)
    - 본 적 있는지는 `sessionStorage`에 `state/`의 저장소 래퍼로 적는다(사생활 보호 모드에서 실패하면 매번 뜬다. 앱은 멈추지 않는다)
  - **S-01 언어 선택 벤토 그리드** `/`
    - 위: 질문 h1 `어떤 언어로 이야기할까요?`(`langAsk`, 폰 언어) + 폰 언어가 영어가 아니면 아래 영어 한 줄. 지금과 같다. 안내원 동그라미와 말풍선은 없다
    - 격자: 6칸 격자, 타일 사이 8px. 폰 언어 추천(`suggestLangs`, 지금 규칙 그대로)으로 크기를 정한다
      | 타일 | 언어 | 폭 | 모양 |
      |---|---|---|---|
      | 큰 타일 1개 | 추천 첫째(폰 언어, 없으면 영어) | 6칸(한 줄 전체) | 색이 있는 면 `--brand`, 흰 글자. 국기 크게, `한국어로 할게요`(`langReply`, 그 언어로), 영어 이름 작게. 높이 112px 이상 |
      | 중간 타일 0~3개 | 추천 나머지(가까운 언어·영어) | 3칸(두 개씩). 홀수면 마지막 하나는 6칸 | 떠 있음 `--glass`, `--brand-2` 바탕. 국기 + 모국어 이름 크게 + 영어 이름 |
      | 작은 타일 16~19개 | 나머지 언어(`rest`, 지금 순서) | 2칸(세 개씩). 마지막 줄이 하나 남으면 6칸, 둘 남으면 3칸씩 | 떠 있음 `--glass-sm`, `--card`. 국기 + 모국어 이름 + 영어 이름 작게. 높이 76px 이상 |
    - 모든 타일은 버튼 하나이고 누르면 지금처럼 언어를 정하고 다음 단계로 간다. 누르면 들어간다(`--glass-in`)
    - "다른 언어" 제목(`langOther`)은 큰·중간 타일과 작은 타일 사이에 h2로 남긴다
    - 아래: `langHint`, `센터 상담원 화면 →` 링크 — 지금 그대로
    - RTL(아랍어 폰)에서 격자는 오른쪽부터 채워진다
  - `design.md`: "말풍선" 절을 "언어 벤토 그리드" 절로 바꾸고 "스플래시" 절을 더한다. 면·흐림·둥글기 표에서 말풍선·알약 언급을 타일로 바꾼다
  - `styles.css`: `.w-chat` 규칙을 지우고 `.w-splash`, `.lang-bento` 규칙을 더한다
  - `README.md` 화면 구성 표의 S-01 설명(대화형 → 벤토 그리드, 스플래시 한 줄)
- 하지 않는 것
  - 추천 규칙(`suggest.ts`) 변경. 어떤 언어가 크게 보이는지는 지금과 같다
  - 새 경로. 스플래시는 경로가 아니다
  - 로고 이미지·앱 이름 변경, 스플래시 배경 그림
  - 언어 검색창
  - 동의·로그인 화면

## 결과
- 실행(2026-10-30, 브랜치 `frontend/splash-bento-lang`)
  - `npm run build` → 통과(기존 청크 크기 경고만)
  - 앱 브라우저 창(360×800)에서 확인
    - 저장소를 비우고 `/`: 로고 + `for nav` + 하단 119 띠(`119 · Emergency · Khẩn cấp`), 1.2초 뒤 S-01. 새로고침하면 스플래시 없이 S-01
    - 언어 vi·동의·비회원 상태에서 스플래시 기록만 지우고 `/home`: 스플래시(119 띠는 베트남어) → 화면을 누르면 바로 `/home`
    - 스플래시 기록을 지우고 `/center`: 스플래시 없음
    - S-01 타일 20개, 가로 넘침 0px. `Tiếng Việt` 타일을 누르면 언어 vi로 `/consent`
    - 앱 브라우저의 폰 언어를 바꿀 수 없어서, 페이지 안에서 `suggestLangs`를 폰 언어 ko·vi·ar·en·ru·kk·(지원 안 함 de)로 불러 큰 타일·중간 타일과 줄 채움을 셌다. 일곱 경우 모두 큰 타일이 그 언어(de는 en)이고, 타일 20개이고, 두 격자 모두 빈 칸 없이 줄이 찬다
    - RTL은 S-01 뿌리에 `dir="rtl"`을 붙여 찍었다. 격자가 오른쪽부터 채워진다
- 결정 사항
  - 스플래시를 봤는지는 세션 상태(`umn.session`)가 아니라 따로 `umn.splash`(sessionStorage, 새 파일 `state/splash.ts`)에 둔다. "내 정보 모두 지우기"가 세션 상태를 비워도 스플래시가 다시 뜨지 않게 하려는 것이다
  - 스플래시 앱 이름은 앱 바와 같은 값(언어를 모르면 `for nav`, 알면 `appName`)이다. 지금 20개 언어 모두 `for nav`다
  - `WorkerLayout`의 탭 제목 `useEffect`를 진입 가드의 이른 `return`보다 위로 옮겼다. 스플래시가 이른 `return`을 하나 더 만들어, 그 아래에 훅이 있으면 스플래시가 끝날 때 훅 개수가 바뀐다. 119 띠 마크업은 스플래시와 본 화면이 같이 쓰도록 변수 하나로 묶었다
  - 타일에는 흐림을 달지 않았다(20개를 한 화면에서 흐리면 저가형 폰이 끊긴다). 칩과 같은 규칙이다
  - `.w-chat` 규칙(안내원·말풍선·알약)은 쓰는 곳이 없어져 지웠다. 그 안의 안내원 동그라미가 없는 토큰 `--clay-sm`을 쓰고 있었는데 함께 없어졌다
- 남은 문제
  - Windows 데스크톱 Chrome은 국기 이모지를 `KR` 같은 글자로 그린다(지금까지와 같다). 휴대폰에서는 국기로 보인다
  - 실제 아랍어 폰(폰 언어 ar)으로는 보지 못했다. 큰 타일이 ar인 것은 추천 결과로, RTL 배치는 `dir` 강제로 각각 확인했다

## 메모
- 폰 언어는 브라우저 설정(`navigator.languages`)이다. 확인할 때는 앱 브라우저의 언어를 바꾸는 대신 추천 결과를 바꿔 본다
- 대화형 화면(backlog 20·22)의 안내원·대답 말풍선·국기 알약은 이 항목으로 없어진다. `design.md`의 해당 결정 기록은 이 문서로 옮긴다
