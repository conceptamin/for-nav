# 51. 센터 C-02 통화·채팅을 한 상담 카드로: 채팅 시트 같은 메신저 틀 + 채팅/스크립트 전환

상태: 진행 중
의존: 47(채팅 메신저 모양), 48(사례 상세 배치)

## 목표
근로자 화면에서 플로팅 채팅 아이콘을 누르면 나오는 센터 채팅 시트처럼, 센터 C-02의 통화·상담 채팅도 머리 / 대화 줄기 / 아래 고정 입력줄의 메신저 틀로 보인다. 자리는 오른쪽 열 그대로다(2026-10-31 사용자 요청).
이어서 통화 박스와 채팅 박스를 하나로 합치고, 통화할 때는 채팅 자리를 통화 스크립트(자막) 창으로 바꿀 수 있게 한다(2026-10-31 사용자 요청).

## 지금 화면에서 본 것
- 통화·상담 채팅은 각각 일반 패널이다: 회색 제목(`h2`) + 작은 안내 + 들어간 홈(`.chat-log`·`.call-log`) + 그 아래 입력줄·버튼
- 근로자 시트는 머리(마크·제목·요청 번호) / 홈 없는 대화 줄기 / 아래 고정 칸으로 되어 있어 두 화면의 모양이 다르다

## 범위
- 하는 것
  - C-02 오른쪽 열의 통화·상담 채팅 패널 둘을 상담 카드 하나(`.panel.talk`)로 합친다. 안은 시트와 같은 `.sheet-head` / 통화 줄 `.talk-bar` / `.sheet-body` / `.sheet-foot`
  - 머리: 근로자 선 아이콘, 제목 "상담", 아래 `근로자 · 언어`, 끝 쪽 `채팅` / `스크립트` 보기 전환(`.toggle.talk-mode`)
  - 통화 상태·버튼은 머리 아래 통화 줄에 늘 보인다(어느 보기에서든 전화를 놓치지 않게, `CallPanel`에 `scroller`·`footer` 추가)
  - 대화는 채팅 메시지 또는 통화 스크립트 중 하나만 보인다. 둘 다 늘 붙어 있고 숨기기만 한다(연결·입력 중인 글·자막 유지). 채팅 입력줄은 채팅 보기에서만 아래 칸에
  - 스크립트를 보는 사이 근로자 채팅이 오면 `채팅` 버튼에 점(`ChatPanel`에 `onPeerCount` 추가). 읽음은 채팅 보기일 때만 보낸다
  - 카드 안 채팅·자막 목록은 홈 없이 대화 줄기의 일부로, 상대 말풍선은 `--card-solid`
- 하지 않는 것
  - 통화가 시작되면 스크립트로 저절로 바꾸기(사람이 고른다)
  - 근로자 시트 모양 변경(`CallPanel`은 `footer`가 없으면 전과 같다)
  - 문구 외 API 변경

## 결과
- `npm run build` → 통과. `cd app-front && npm run build` → 통과
- API 모드(백엔드 Python 3.12 + `tzdata`, 근로자 인증 꺼짐)에서 API로 실제 사례를 만들고 근로자 쪽은 WebSocket으로 글을 보냈다
  - 채팅 보기: 날짜 줄, 근로자 말풍선(시작 쪽), 센터 답장(끝 쪽, `안 읽음`·시각), 아래 고정 입력줄. 콘솔 오류 없음
  - 스크립트 보기로 바꾼 뒤 근로자 글 하나: `채팅` 버튼에 점, 채팅 칸·입력줄 숨김, 아래 칸 없음. 채팅으로 돌아오니 점이 사라지고 새 글 포함 3개, 맨 아래로 스크롤, 입력 중이던 글 유지
  - 근로자 통화 소켓 연결 뒤 통화 줄 `전화 걸기`가 눌릴 수 있음
- 결정: 시트는 통화·채팅을 머리 버튼으로 오가며 통화 화면에 버튼까지 함께 바뀌지만, C-02는 통화 줄을 대화 바깥에 두고 대화만 채팅/스크립트로 바꾼다
