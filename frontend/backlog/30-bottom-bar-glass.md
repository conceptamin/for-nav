# 30. 하단 119·센터 채팅 버튼 글래스 다듬기

상태: 완료
의존: 25 (하단 119 버튼), 29 (하단 센터 채팅 아이콘)

## 목표
2026-10-31 사용자 요청: "119, 채팅 아이콘 글래스모피즘으로 조금 더 감각적으로 바꿔주고, 채팅 아이콘 크기를 좀 가로로 키워줘." 하단 띠의 두 버튼에 유리 두께감(위쪽 빛 반사, 아래 안쪽 음영)을 더하고, 채팅 버튼을 44px 원에서 가로로 긴 알약으로 바꾼다.

## 범위
- 하는 것
  - 119 버튼: 위→아래로 짙어지는 반투명 빨강(`--danger-glass-top` 88% → `--danger-glass-bottom` 90%) + 위쪽 빛 반사(`--glass-sheen-color`) + 아래 안쪽 음영(`--glass-color-lift`) + 글자 아래 옅은 그림자. 누르면 빛 반사 없이 `--glass-color-in`
  - 센터 채팅 버튼: 72×44px 알약, 틸을 비친 유리(`--card-tint`) + 위쪽 빛 반사(`--glass-sheen`) + `--glass-lift`. 아이콘 24px → 26px. 지금 화면·누름은 `--brand-2` + `--glass-in`. 마우스가 있는 기기에서만 호버(`--card-hover`)
  - 두 버튼 사이 간격 12px → 10px
  - `styles.css` `:root` 토큰과 `design.md`(색이 있는 면 예외, 고정 띠, 바탕 표, 그림자 토큰)
- 하지 않는 것
  - 띠 높이(`--bar-119` 64px)·버튼 높이(44px)·문구·동작 변경
  - 색이 있는 빛(glow) 그림자, 움직이는 효과
  - 119를 더 투명하게 하는 것(흰 글자 4.5:1)

## 화면·파일
- 화면: 하단 119 띠가 있는 근로자 화면 전부(응급 화면·스플래시 제외). 경로 변경 없음
- 파일: `src/styles.css`, `src/components/WorkerLayout.tsx`(아이콘 크기), `design.md`
- `app-front/`는 `styles.css`·`WorkerLayout`을 공유 import하므로 같은 모양이 된다

## 완료 기준
- [x] `npm run build` 통과
- [x] 채팅 버튼이 72×44px, 119가 44px 안(두 줄로 접히는 uz도 넘침 없음)
- [x] 119 글자 자리의 가장 밝은 곳에서 흰 글자 대비 4.5:1 이상(계산 4.6:1)
- [x] ko·vi·uz·ar(RTL)·my에서 확인

## 결과
- `cd frontend && npm run build` → 통과
- 브라우저(dev 서버 5180, 데모 로그인 상태)
  - 375px `/home` ko: 119(위가 밝고 아래로 짙은 빨강, 빛 반사) 왼쪽, 틸 유리 알약 채팅 버튼 오른쪽
  - 375px `/center-chat` vi: 채팅 버튼이 지금 화면이라 `--brand-2` 들어간 면
  - 360px `/home` uz: 119 두 줄, 높이 44px, 넘침 없음. ar: 채팅 버튼 왼쪽(16px), 119 오른쪽. my: 44px
  - 콘솔 오류 없음
- 결정
  - 119 대비: 빛 반사를 얹으면 위쪽이 밝아져 흰 글자 대비가 떨어진다. 위쪽 빨강을 85% → 88%로 더 불투명하고 조금 짙게(`rgb(190 26 16)`) 하고 빛 반사를 14%·위 40%로 줄여, 두 줄 글자의 윗줄 자리(높이 5~10%)에서도 약 4.6:1을 지킨다
  - 채팅 버튼은 119와 높이를 맞춰 44px로 두고 가로만 72px로 늘렸다. 띠 높이가 그대로라 `.w-main`·`.w-footer` 여백을 바꾸지 않는다

## 메모
- 대비 계산은 가장 밝은 바닥(`--bg` 근처) 기준이다. 바닥 빛 번짐 알파를 바꾸면 다시 잰다
