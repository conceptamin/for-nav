# 56. 접수함 mock 사례를 센터 회신 분포로 바꾸기

상태: 완료
의존: 51(통계 원천)

## 목표
2026-10-31 사용자 요청("사례 접수함에는 왜 없어"): 51에서 C-03 통계 원천만 센터 의료 상담실적 엑셀(동구 센터, 329건) 분포로 바꿔 C-01 접수함 mock 사례 24건은 여전히 베트남어·영어, 북구 중심, 업무 중 부상 위주였다. 사례도 같은 분포를 따른 합성값으로 바꾼다. 저장소가 공개라 엑셀 행·상담 내용은 넣지 않는다(51과 같은 결정).

## 범위
- 하는 것
  - `data/mock.ts` 사례 언어 `LANG_W`: ru 44·id 25·si 15·en 8·tl 4·vi 2(51 `STAT_LANG_W`에서 한국어를 뺀 것, 한국어 사례는 실제 전송으로만)
  - 구군: 51의 `STAT_DISTRICT_W`를 `DISTRICT_W`로 합쳐 사례·통계가 같은 표(동구 196·북구 20·울주 17·남구 8)를 쓴다
  - 요청 종류 `REQ_W`: 통번역 50·예약 20·제도 15·기관 연계 10·기타 5(회신 상담 대부분이 진료 통역, 건강보험 문의 12%). 통계 원천도 같은 표다(C-03에 요청 종류 칸은 없다)
  - 연락 방식 `CONTACT_W`: 전화 67·방문 30·카카오톡 3(회신 상담 방법 전화 67%, 방문·출장 30%)
  - 장면 12개를 회신에 많던 상담(치과·소화기·산부인과 통역, 건강보험증 미수령)과 업무 중 부상으로 바꾸고 자유 입력 문장을 ru·id·si·en·tl·vi 여섯 언어로 쓴다. 엑셀 상담 내용을 옮기지 않은 합성 문장이다
  - 서버 `backend/app/data/mock.py`를 같은 PR에서 맞춘다(51과 같은 결정), `parity.json` 재생성
- 하지 않는 것
  - 엑셀 행·상담 내용·성별·비자를 저장소에 넣기
  - 사례 개수(24건)·상태·날짜 규칙, 동의 항목
