# 28. 앱 바 언어 변경을 글래스 번역 아이콘으로

상태: 완료
의존: 없음(18 브랜드 틸, 21 글래스모피즘 위에서 한다)

## 목표
2026-10-31 사용자 요청: 앱 우측 상단의 언어 선택 드롭다운(`한국어 ▾` select)을 언어 변환 아이콘 버튼으로 바꾼다. 아이콘은 사용자가 준 참고 이미지처럼 두 장의 카드가 겹치고 앞 카드에 `A`, 뒤 카드에 `文`이 있는 둥근 외곽선 번역 아이콘이고, 글래스모피즘으로 헤더의 틸 로고와 어울리게 한다. 언어 변경 기능은 그대로 둔다.

## 범위
- 하는 것
  - `src/components/LangMenu.tsx`(새 파일): 번역 아이콘(인라인 SVG) + 지금 언어 코드 배지 버튼, 누르면 아래로 열리는 20개 언어 목록. 메뉴 버튼 패턴의 키보드 조작과 `aria-*`
  - `WorkerLayout`: 앱 바의 `select`를 `LangMenu`로 바꾼다. 언어를 고르기 전(S-01)에는 지금처럼 보이지 않는다
  - `styles.css`: `.lang-pick`·`.lang-btn`·`.lang-code`·`.lang-menu`, 토큰 `--card-hover`. 앱 바 흐림을 `.w-header::before`로 옮긴다(목록이 본문을 흐릴 수 있게)
  - `design.md`: "앱 바 언어 변경" 절, 흐림·둥글기·바탕 표, 호버 예외
- 하지 않는 것
  - 새 의존성(아이콘 라이브러리), 그림 파일
  - 새 i18n 키. 이름은 기존 `changeLang`을 쓴다
  - 열고 닫는 애니메이션(design.md "애니메이션 없음")
  - S-12 `/my`의 언어 select(`#my-lang`)는 그대로 둔다

## 화면·파일
- 화면: 근로자 앱 바가 있는 모든 화면(`/home`, `/intake`, `/coverage`, `/result`, `/report*`, `/my` 등). 경로 변경 없음
- API: 없음
- 파일: `src/components/LangMenu.tsx`, `src/components/WorkerLayout.tsx`, `src/styles.css`, `design.md`
- `app-front/`는 `WorkerLayout`·`styles.css`를 `@fe`로 공유 import하므로 함께 바뀐다. `.w-header button.back` 선택자는 바꾸지 않았다

## 결과
- `cd frontend && npm run build` → 통과(타입 검사 + 빌드, 청크 크기 경고만 기존과 같다)
- `cd app-front && npm ci && npm run build` → 통과
- 브라우저(dev 서버 5180, 비회원 상태로 세션 저장소를 채워 확인)
  - 데스크톱 폭 `/home` ko: 버튼(아이콘 + `KO`), 목록 열기, 마우스 올림 강조, 한국어 줄 ✓
  - 휴대폰 폭 375px `/home` vi: 목록 240px가 16px~359px 안에 들어온다. 언어를 고르면 버튼 이름 `Ngôn ngữ: Tiếng Việt`, 배지 `VI`, 포커스가 버튼으로 돌아온다
  - 375px `/home` ar: 버튼이 왼쪽, 목록이 왼쪽 16px에 붙고 한국어 줄까지 모든 이름이 오른쪽(시작 쪽)에 붙는다
  - 375px `/intake` ko: ← + 로고 + 버튼 한 줄, 앱 바 높이 56px, 목록이 바닥 버튼 띠 위에 그려진다
  - 콘솔 오류 없음
- 결정
  - 지금 언어를 코드 배지(`KO`)로 보인다. 아이콘만으로는 지금 무슨 언어인지 알 수 없다. 코드는 `Lang` 값을 대문자로 쓴다(`ZH-CN`, `ZH-TW`가 갈린다)
  - 목록은 줄마다 모국어 이름 + 영어 이름. S-01 언어 격자와 같은 정보이고 국기는 넣지 않았다(좁은 목록에서 국기가 언어와 1:1이 아닌 점이 더 눈에 띈다)
  - 앱 바 흐림을 `::before`로 옮겼다. `backdrop-filter`가 있는 상자 안의 자식은 상자 밖을 흐리지 못해, 그대로 두면 목록이 본문 위에서 흐림 없이 비친다
  - 호버는 `@media (hover: hover)` 안에서만 단다. 근로자 화면의 "호버 없음" 규칙의 예외이고, 요청에 hover 상태가 있었다
  - 목록 줄의 `lang`은 버튼이 아니라 이름 칸에 단다. 버튼에 달면 RTL 화면에서 `[lang='ko']` 규칙이 한국어 줄 전체를 LTR로 돌린다
