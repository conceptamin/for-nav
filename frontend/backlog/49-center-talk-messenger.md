# 49. 센터 C-02 통화·채팅을 근로자 채팅 시트와 같은 메신저 틀로

상태: 진행 중
의존: 47(채팅 메신저 모양), 48(사례 상세 배치)

## 목표
근로자 화면에서 플로팅 채팅 아이콘을 누르면 나오는 센터 채팅 시트처럼, 센터 C-02의 통화·상담 채팅도 머리 / 대화 줄기 / 아래 고정 입력줄의 메신저 틀로 보인다. 자리는 바꾸지 않는다(2026-10-31 사용자 요청).

## 지금 화면에서 본 것
- 통화·상담 채팅은 각각 일반 패널이다: 회색 제목(`h2`) + 작은 안내 + 들어간 홈(`.chat-log`·`.call-log`) + 그 아래 입력줄·버튼
- 근로자 시트는 머리(마크·제목·요청 번호) / 홈 없는 대화 줄기 / 아래 고정 칸으로 되어 있어 두 화면의 모양이 다르다

## 범위
- 하는 것
  - C-02 오른쪽 열의 통화(위)·상담 채팅(아래) 패널을 `.panel.talk` 카드로 바꾸고, 안에 시트와 같은 `.sheet-head` / `.sheet-body` / `.sheet-foot`을 쓴다
  - 머리 시작 쪽은 상대(근로자) 선 아이콘, 제목 아래 `근로자 · 언어`
  - 카드 안내 문구는 대화 맨 위 시스템 줄(`.chat-sys`)로 옮긴다
  - 채팅 입력줄은 아래 칸에(`ChatPanel`의 `footer`), 통화 상태 줄·안내·버튼 줄도 아래 칸에 둔다(`CallPanel`에 `scroller`·`footer` 추가)
  - 카드 안 채팅·자막 목록은 홈 없이 대화 줄기의 일부로, 상대 말풍선은 `--card-solid`
- 하지 않는 것
  - 자리 이동, 통화·채팅 전환 버튼(둘을 함께 보인다. 전화 오는 것을 놓치지 않게)
  - 근로자 시트 모양 변경(`CallPanel`은 `footer`가 없으면 전과 같다)
  - 문구·API 변경

## 화면·파일
- 화면: C-02 `/center/cases/:id`
- 수정: `src/pages/center/Center.tsx`(`TalkHead`·`CenterCall`·`CenterChat`), `src/components/CallPanel.tsx`(`scroller`·`footer`), `src/styles.css`(`.panel.talk`·`.talk-*`, `.detail .chat-log` 삭제), `design.md`(상담 채팅·통화·센터 사례 상세)

## 완료 기준
- [x] `npm run build` 통과, `cd app-front && npm run build` 통과(`styles.css` 공유)
- [x] API 모드 C-02 오른쪽 열이 통화 카드(위) · 채팅 카드(아래) 그대로이고, 둘 다 머리 / 대화 / 아래 칸 틀이다
- [x] 근로자 글은 시작 쪽, 센터 글은 끝 쪽 말풍선이고 입력줄이 카드 아래에 고정된다
- [x] 근로자가 통화 소켓에 있으면 아래 칸의 `전화 걸기`가 눌릴 수 있다

## 결과
- `npm run build` → 통과. `cd app-front && npm run build` → 통과
- API 모드(백엔드 Python 3.12 + `tzdata`, 근로자 인증 꺼짐)에서 API로 실제 사례 C-98678을 만들고 근로자 쪽은 WebSocket으로 글 세 개를 보냈다. C-02에서 답장을 보내니 끝 쪽 말풍선 + `안 읽음`·시각, 날짜 줄, 대화 맨 위 안내 시스템 줄이 보였다. 콘솔 오류 없음
- 예시 사례 C-1024: 통화 카드 아래 칸에 `근로자가 화면에 없어…` 상태 줄과 막힌 `전화 걸기`, 채팅 카드 대화에 예시 사례 안내
- 결정: 시트는 통화·채팅을 머리 버튼으로 오가지만 C-02는 자리를 지키고 둘을 함께 보인다
