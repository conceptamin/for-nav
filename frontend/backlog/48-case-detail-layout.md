# 48. 센터 사례 상세 배치: 상태 변경을 머리 줄로, 사례 정보를 왼쪽으로, 채팅을 길게

상태: 진행 중
의존: 없음

## 목표
C-02 `/center/cases/:id`에서 직원이 가장 자주 누르는 상태 변경을 제목 줄 오른쪽에 두고, 읽기만 하는 사례 정보 패널들을 왼쪽 열 아래로 옮긴다. 그렇게 비운 오른쪽 열 세로 자리를 상담 채팅 목록에 준다(2026-10-31 사용자 요청).

## 지금 화면에서 본 것
- 제목 줄(`← 접수함` · `사례 C-xxxxx` · 긴급도·상태·실제 전송 칩) 오른쪽이 비어 있다
- 오른쪽 열에 통화 · 상담 채팅 · 상태 변경 · 사례 정보 · 제도 경로 결과 · 연락 희망 방법이 쌓여, 채팅 목록은 최대 320px로 짧다

## 범위
- 하는 것
  - 상태 변경(신규·진행·완료 버튼 셋)을 제목 줄 끝 쪽에 내용 폭만큼의 떠 있는 상자(`.status-box`)로 둔다. 좁으면 다음 줄로 내려간다. 실패 문구 + 다시 시도는 제목 줄 바로 아래 한 줄로 둔다
  - 사례 정보 · 제도 경로 결과 · 연락 희망 방법을 왼쪽 열(한국어 요약 · 모국어 원문 · 동의 항목) 아래로 옮긴다. 단, 통화·채팅이 둘 다 없는 단독 모드에서는 오른쪽 열이 비므로 세 패널을 오른쪽 열에 둔다
  - 오른쪽 열에는 통화와 상담 채팅만 남기고, C-02 채팅 목록 높이를 320~600px(화면 높이의 60%)로 고정한다
- 하지 않는 것
  - 패널 내용·문구·API 호출 변경
  - 근로자 센터 채팅 시트의 채팅 모양 변경(시트 안 `.chat-log`는 그대로)
  - 통화 자막 목록 높이 변경

## 화면·파일
- 화면: C-02 `/center/cases/:id`. 경로·API·문구 키 변경 없음
- 수정: `src/pages/center/Center.tsx`(`CaseDetail`), `src/styles.css`(`.detail-head`, `.status-box`, `.detail .chat-log`), `design.md`(센터 사례 상세 절, 상담 채팅 목록 높이)

## 결과
- `npm run build` → 통과. `cd app-front && npm run build` → 통과
- 단독 모드 `/center/cases/C-1017`
  - 1280px: 상태 변경 상자가 제목 줄 끝(오른쪽 1256px, 제목과 같은 줄). 왼쪽 열 요약 · 원문 · 동의 항목, 오른쪽 열 사례 정보 · 제도 경로 결과 · 연락 희망 방법. `신규`를 누르면 상태 칩이 `신규`로 바뀌고, `진행`을 눌러 되돌렸다
  - 860px: 한 줄에 들어가고 가로 넘침 없음(문서 폭 845px = 화면 폭에서 스크롤바를 뺀 값). 600px: 상자가 제목 아래 줄 끝 쪽으로 내려가고 넘침 없음
  - 채팅 목록 CSS: `.detail` 안에 시험용 `.chat > .chat-log`를 넣어 재면 높이 540px(화면 높이 900px의 60%), 시트 안(`.sheet .chat-log`)은 그대로 높이 없음·`max-height: none`
- 결정: 단독 모드는 통화·채팅이 없어 세 패널을 왼쪽으로 옮기면 오른쪽 열이 비므로, 통화·채팅이 하나라도 있을 때만 왼쪽 아래로 옮긴다
- 결정: 채팅 목록은 메시지 수와 관계없이 같은 높이로 고정해(`clamp(320px, 60dvh, 600px)`) 비운 오른쪽 열 세로 자리를 채운다
- 남은 문제: API 모드 실제 화면은 확인하지 못했다. 이 PC에서 백엔드가 뜨지 않았다(worktree 새 venv는 Python 3.15라 pyyaml 빌드 실패, 메인 체크아웃 venv는 `Asia/Seoul` 시간대 자료 없음). 위 두 칸은 API 모드에서 확인하면 체크한다
