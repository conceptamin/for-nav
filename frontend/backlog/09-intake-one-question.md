# 09. S-05 추가 질문을 질문 하나씩 화면으로

상태: 대기
의존: 08 (앱 바 ←, `.w-footer`, `.options`, `Steps`가 있어야 한다)

## 목표
S-05 4단계 "추가 질문"이 한 화면에 `field` 여덟 개(발생 시점·통증 점수·다침·업무 관련·업무 종류·나이대·성별·업종·구군)를 쌓아 놓은 것을 `design.md` "화면 골격(Figma 기준)"대로 **화면 하나에 질문 하나**로 나눈다. "지금 코드와 다른 점" 6번과, 8번 중 "둘뿐인 예/아니요는 바닥 버튼 위에 붙인다"가 이 항목이다. 응급 감지·추출·판정 호출 시점과 결과는 바꾸지 않는다.

## 범위
- 하는 것
  - `Intake.tsx`의 단계를 두 층으로: 묶음(부위·증상·자유 입력·추가 질문, 숫자 원 1~4) 안에 질문(추가 질문 묶음만 여러 개). 상태는 `group`과 `question` 두 숫자. 숫자 원은 묶음 단위로 센다
  - 추가 질문 순서: 발생 시점 → 통증 점수 → 다침 → 업무 관련 → (업무 관련이 예일 때만) 업무 종류 → 나이대 → 성별 → 업종 → 구군. 질문마다 h1 하나 + 입력 도구 하나 + 바닥 `다음`(마지막 질문은 `결과 보기`)
  - 예/아니요(다침, 업무 관련)는 h1 아래가 아니라 바닥 버튼 바로 위에 붙인다: `.w-footer` 안에 `.options`를 버튼 위에 둔다(`YesNoSeg`를 `footer` 슬롯으로 받는다)
  - 통증 점수는 `select`에서 "슬라이더" 도구로: 얼굴 아이콘(이모지, `aria-hidden`) + 단계 이름(`약함`·`보통`·`심함`) → 숫자 크게 → `input[type=range]`(0~10) → 양 끝 `0 · 없음`·`10 · 최악`. `input[type=range]` 트랙은 들어감, 손잡이는 떠 있음(`styles.css`에 더한다). 새 문구 키 `painMild`·`painModerate`·`painSevere`
  - 추출(`extract`)이 채운 답은 해당 질문에 미리 골라져 보인다. `extractedNote` 안내는 추가 질문 묶음의 첫 질문 위에 한 번만
  - ← (앱 바)는 질문 하나씩 되돌아간다. 묶음의 첫 질문에서는 앞 묶음으로
  - `design.md` "지금 코드와 다른 점"에서 6번과 8번의 남은 문장을 지우고, 절이 비면 절 자체를 지운다. 컴포넌트 표에 슬라이더(`.range`) 줄을 더한다
- 하지 않는 것
  - 질문 추가·삭제·문구 변경, 열거값 변경. 선택 안 함(건너뛰기)의 의미도 그대로(답하지 않으면 키가 없다)
  - 그림 고르기(부위 그림). 자산이 없다
  - 한 질문에 답하면 자동으로 다음으로 넘어가기. 바닥 `다음`을 눌러야 넘어간다(잘못 누름을 되돌릴 수 있어야 한다)

## 화면·파일

- 새 문구 키: `painMild`, `painModerate`, `painSevere`
