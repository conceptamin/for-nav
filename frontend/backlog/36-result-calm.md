# 36. S-07 진료 안내 화면의 버튼·안내 상자 정리

상태: 완료
의존: 35

## 목표
S-07 `/result`는 한 화면에 주 색 버튼 4개, 보조 버튼 4개, 색 있는 안내 상자 2개(빨강·노랑)가 쌓여 무엇부터 눌러야 할지 보이지 않는다. 주 동작을 "첫 진료과 지도" 하나로 두고, 나머지는 홈 메뉴와 같은 목록 줄로 묶어 화면의 무게를 줄인다.

## 지금 화면에서 본 것 (360px, ko, 2026-10-31)
1. 브랜드색 버튼이 `지도에서 찾기 — 정형외과`, `전화 예약 문장`, `접수 창구에 보여 주기`, `의사에게 보여 줄 메모` 네 개다. `design.md` Don't "브랜드 색을 넓게 칠하지 않는다"와 어긋난다
2. 위에 빨강 `심해지면 119` 상자, 가운데 노랑 `지도에서 진료 시간 확인` 상자, 아래 각주까지 안내가 세 겹이다
3. `접수 창구에 보여 주기`의 🪪 이모지가 Windows에서 빈 네모(▯)로 보인다
4. 화면 높이 약 1030px로 360×760에서 두 번 스크롤해야 끝까지 보인다

## 범위
- 하는 것
  - 첫 진료과 상자 안의 지도 버튼 하나만 브랜드색 주 버튼. 이곳도 가능(두 번째 진료과)은 글자 링크 크기의 보조 버튼
  - "병원에 갈 때" 묶음: 전화 예약 문장 · 접수 창구 · 의사 메모를 홈 메뉴(`.menu-list`)와 같은 목록 줄(아이콘 칸 + 제목 + ›)로
  - "더 도움이 필요하면" 묶음: 보험과 지원 · 센터에 도움 요청 · 가까운 약국 · 가까운 응급실을 같은 목록 줄로
  - 노랑 지도 안내 상자를 첫 진료과 상자 안 작은 글로 옮긴다. 빨강 `심해지면 119`(`Worse119`)는 그대로 둔다
  - 이모지 아이콘을 홈 메뉴와 같은 아이콘 칸으로 바꿔 빈 네모가 생기지 않게 한다
- 하지 않는 것
  - 경로·이동 대상·문구 의미 변경. 진단 표현 금지 각주(`resultNoDiag`)는 그대로
  - 응급 화면(`/emergency`)

## 화면·파일

- 수정: `src/pages/worker/Intake.tsx`(`ResultPage`), `src/styles.css`, `design.md`. 묶음 제목 문구 키 2개(`resultGoGroup`, `resultMoreGroup`)를 20개 언어에 더한다

- [x] 이동 대상 9개(지도 2·약국·응급실·전화·창구·메모·보험·센터)가 지금과 같은 곳으로 간다 — 보험·센터 2개는 사용자 결정으로 뺐다(아래 "결정"). 남은 7개는 지금과 같은 곳이다

## 결과
- 실행: `npm run build` → 통과. `cd app-front && npm run build` → 통과(`pages/worker/*`·`styles.css` 공유, 경로 표 수정)
- 브라우저(단독 모드, 360×760, Windows Chromium, 2026-10-31). `/result`는 `sessionStorage`의 `umn.session`에 입력·진료과(정형외과/외과)를 넣고 열었다
  - ko·en·vi·ar: 브랜드색 버튼(`.btn` 중 `secondary`·`ghost`가 아닌 것)은 `지도에서 찾기 — 정형외과` 하나이고, `.notice`는 `심해지면 119` 하나다. 목록 줄·버튼 글자 잘림과 가로 넘침은 없다. ar은 `dir="rtl"`이다. 아이콘 칸은 오른쪽, 시트 ✕는 왼쪽, 다른 진료과 지도 링크는 시작 쪽(오른쪽)에 붙는다
  - 이동 대상 7개: 카카오맵 정형외과·외과·약국·응급실, `/visit/call`, `/visit/desk`, `/report/new`
  - 밤·휴일 시트(backlog 44 after-hours-guide 후속 2)
    - "밤이나 휴일이라면" 줄을 누르면 `role="dialog"` 시트가 뜨고 초점이 시트로 간다. 뒤 화면 스크롤이 묶이고 경로는 `/result` 그대로다. 시트 높이는 ko 213px, ar 261px, vi 285px이다. 119 독은 시트 아래에 그대로 보인다
    - ✕·Esc·막 누르기 셋 다 닫히고 스크롤 묶기가 풀린다
  - 스크린숏에서 아이콘 칸 6개(📞📋📝💊🚑🌙)와 🗺️가 모두 그려졌다(빈 네모 없음)
  - 화면 높이: ko 1178px, en 1262px. 바꾸기 전은 약 1090px(밤·휴일 버튼 포함)이었다
- 바뀐 화면: S-07 `/result`. `/after-hours` 경로를 뺐다(44 후속 2)
- 결정
  - 목록은 홈과 같은 `.home-list`를 그대로 쓰고, 줄에는 부제 없이 제목 하나만 둔다. 시트를 여는 줄만 `button`이고 모양은 같다(`.home-list a, .home-list button`). `design.md` "진료 안내"에 적었다
  - "더 도움이 필요하면"에서 보험과 지원·센터에 도움 요청을 뺐다(2026-10-31 사용자 결정). 둘 다 홈 기능 목록에 있고, 센터는 하단 채팅 아이콘으로도 열린다
  - 지도 안내(`mapNotice`+`mapOpens`)를 첫 진료과 상자 안 `.dept-note`(`--t3` `--ink-2`)로 옮기고 ☎️는 뺐다
  - 다른 진료과 지도는 `.btn.ghost.dept-alt-map`이다(높이 44px, `--t4`, 끝에 `›`). 🗺️를 붙이면 다시 버튼처럼 보여서 뺐다
  - 🩺(Emoji 12)를 📝(Unicode 6.0)로 바꿨다. 🪪는 37에서 이미 📋로 바뀌어 있었다
  - 문구 키 `resultGoGroup`·`resultMoreGroup`을 20개 언어에 넣었다(en·ko는 직접 썼고 나머지는 기계 번역 초안이다)
- 남은 문제: 화면 높이가 약 90~170px 늘었다. 목록 줄 높이가 홈과 같은 64px이기 때문이다. 색과 버튼 수는 줄었지만 스크롤은 조금 길다
