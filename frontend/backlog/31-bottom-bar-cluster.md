# 31. 하단 119·센터 채팅 버튼을 한쪽에 모아 띄우기

상태: 완료
의존: 29 (하단 센터 채팅 아이콘), 30 (하단 버튼 글래스)

## 목표
2026-10-31 사용자 요청: "아이콘 119, 채팅 모두 한 쪽에 떠있게 해줘. 위치는 너가 알아서 조정." 지금은 119가 왼쪽, 채팅이 오른쪽 끝으로 벌어져 있다. 두 버튼을 한 묶음으로 화면 한쪽에 띄운다.

## 범위
- 하는 것
  - 두 버튼을 끝 쪽(오른쪽, RTL이면 왼쪽)에 간격 8px로 붙인다. 채팅이 가장자리, 119가 그 안쪽
  - 119 혼자일 때(로그인 전)도 같은 끝 쪽에 둔다
  - `design.md` 고정 띠 설명
- 하지 않는 것
  - 버튼 모양·크기·높이(44px)·띠 높이(64px)·문구·동작 변경
  - 세로로 쌓기(띠 높이가 늘어 본문 아래 여백·`.w-footer` 자리를 다시 잡아야 한다)

## 화면·파일
- 화면: 하단 119 띠가 있는 근로자 화면 전부(응급 화면·스플래시 제외). 경로 변경 없음
- 파일: `src/styles.css`(`.bar-119`, `.bar-119.with-chat`), `design.md`
- `app-front/`는 `styles.css`를 공유 import하므로 같은 자리가 된다

## 완료 기준
- [x] `npm run build` 통과
- [x] 로그인 뒤 두 버튼이 끝 쪽에 8px 간격으로 붙어 있고, RTL이면 왼쪽 끝에 붙는다
- [x] 로그인 전 119 혼자도 끝 쪽에 있다
- [x] 긴 문구(uz)도 44px 안에서 두 줄로 접힌다

## 결과
- `cd frontend && npm run build` → 통과
- 브라우저(dev 서버 5180, 데모 로그인 상태)
  - 375px `/home` ko: 119(약 182px)와 채팅(72px)이 오른쪽 끝에 붙은 묶음
  - 360px `/home` uz: 119가 16~264px(두 줄, 44px), 채팅 272~344px. 문구가 길어 119가 남은 폭을 채운다
  - 360px `/home` ar: 채팅 16~88px(왼쪽 가장자리), 119 96~313px
  - 360px `/signup`(로그인 전) ko: 119 혼자 146~344px로 오른쪽 끝
  - 콘솔 오류 없음
- 결정
  - 끝 쪽(오른쪽)을 골랐다. 대부분 오른손 엄지가 닿기 쉬운 쪽이고, 떠 있는 버튼의 흔한 자리다. RTL에서는 논리 방향(`flex-end`)을 따라 왼쪽으로 간다
  - 채팅을 가장자리에 둔다. 119는 글자 길이만큼 늘어나므로 안쪽에 두어야 채팅 버튼 자리가 언어마다 같다
  - 119 혼자일 때도 끝 쪽에 둔다. 가운데에 두면 로그인 직후 119 자리가 옮겨 간다
