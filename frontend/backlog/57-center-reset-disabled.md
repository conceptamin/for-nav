상태: 완료
의존: 없음

## 목표
2026-11-01 사용자 요청: 실제 사람들이 센터 화면을 한 번 써 볼 수 있게 맥미니 서버의 센터 로그인을 끈다(`CENTER_AUTH=off`, 코드 변경 없음). 로그인이 없으면 주소를 아는 누구나 C-01 **접수함 초기화**로 모든 사례를 지울 수 있으므로 버튼을 눌리지 않게 막는다.

## 범위
- 하는 것
  - C-01 **접수함 초기화** 버튼을 늘 `disabled`로 둔다. 버튼은 그대로 보인다
- 하지 않는 것
  - 서버 `POST /api/center/reset` 막기(`backend/` 몫. 화면만 막으므로 직접 요청은 여전히 지운다)
  - 센터 로그인 화면(C-00)·`/api/auth/me` 처리 바꾸기. `CENTER_AUTH=off`이면 지금 코드가 로그인 없이 연다

## 화면·파일
