# 57. 센터 화면에서 AX(앱이 대신 한 일)가 드러나게 하기

상태: 완료
의존: 51, 53

## 목표
센터 화면은 근로자 모국어 입력을 한국어 요약·긴급도 근거·제도 경로로 정리하고 채팅·통화를 번역해 주는데, 화면에는 그 일이 평범한 표·패널로만 보여 무엇이 자동인지 드러나지 않았다. 접수함과 사례 상세에서 앱이 대신 한 일을 한눈에 보이고, 상담원이 바로 답할 수 있게 추천 답장을 붙인다(2026-10-31 사용자 요청 "센터 화면에서 AX가 더 잘 드러나게").

## 범위
- 하는 것
  - C-01 KPI 위 `AX 자동 처리` 띠: 한국어 요약 정리 건수, 언어 수, 긴급도 근거가 있는 건수, 제도 경로가 있는 건수, (API 모드) 실제 전송 건수. 모두 사례 필드에서 센다
  - C-01 `요청 유형` 칸 아래 `✦` 한국어 요약 한 줄(말줄임)
  - C-02 제목 줄 아래 `AX 처리 흐름` 다섯 단계(모국어 입력 접수 → 한국어 요약 → 긴급도 분류 → 제도 경로 안내 → AI 통역 상담). 제도 경로가 없거나 예시 사례·단독 모드면 그 단계는 끝나지 않은 것으로 보인다
  - C-02 한국어 사례 요약 패널에 `자동 생성` 칩과 `긴급도 자동 분류` 줄(긴급도 칩 + 근거 칩)
  - C-02 상담 카드 머리에 `✦ AI 실시간 통역` 칩과 `근로자 언어 ⇄ 한국어`
  - C-02 채팅 입력줄 위 추천 답장(실제 전송 사례만): 사례 필드(업무 중 발생·건강보험·요청 유형·긴급도·제도 경로)로 고르는 고정 한국어 문장 최대 5개. 누르면 입력줄에 넣기만 하고, 보내면 서버가 근로자 언어로 번역한다(backend 30)
- 하지 않는 것
  - LLM으로 답장·요약 만들기, 절약 시간 같은 추정 수치 표시
  - 서버 API·규칙·템플릿·mock 변경(parity 영향 없음)
  - 근로자 화면 변경

## 화면·파일
- C-01 `/center`, C-02 `/center/cases/:id`
- `src/pages/center/Center.tsx`: `AxStrip`, `AxFlow`, `suggestReplies`, 요약 패널·상담 카드 머리
- `src/components/ChatPanel.tsx`: 선택 prop `suggestions`·`suggestionsLabel`(근로자 시트는 넘기지 않아 그대로)
- `src/styles.css`: `.ax-*`, `.row-summary`, `.chat-suggest*`, `pill.ax`
- `design.md` "센터 접수함"·"센터 사례 상세" 표에 새 자리
- 새 i18n 키 없음(센터는 한국어 고정)

## 완료 기준
- [x] `npm run build` 통과
- [x] API 모드(백엔드 + `VITE_API_BASE=/api`)에서 C-01에 AX 띠와 요약 줄이 보이고, 근로자가 보낸 사례가 맨 위에 나타난다
- [x] C-02에서 다섯 단계가 사례에 맞게 끝남/남음으로 보이고, 추천 답장을 누르면 입력줄에 들어가며 보내면 근로자 화면에 번역되어 도착한다
- [x] 근로자 채팅 시트에는 추천 답장이 없다

## 결과
- `npm run build` → 통과(타입 검사 + 빌드)
- 확인: 백엔드(:8020, LLM 키 있음) + 프론트 API 모드(:5186)에서 근로자 vi로 증상 입력(사진·자유 입력) → 보험·지원 → 센터 요청 → C-01 맨 위 도착, AX 띠 → C-02 AX 처리 흐름 다섯 단계 모두 ✓ → 추천 답장 `첫 인사`·`산재 안내` 전송 → 근로자 시트에 베트남어 번역 도착, 근로자 답장은 센터에 한국어 번역과 원문 → 통화 자막 번역. Playwright로 1920x1080 소개 영상을 녹화하며 확인했다
- 결정: AX 수치는 사례 필드에서 센 값만 쓴다(추정치는 근거가 없어 넣지 않는다). 추천 답장은 상담원이 고쳐 보낼 수 있게 입력줄에 넣기만 한다
