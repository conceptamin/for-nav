# 53. 센터 접수함에 새 채팅 표시: 위로 올리기, 채팅 시각 정렬, 채팅 모아 보기

상태: 완료
의존: 47(읽음 표시, backend 28)

## 목표
2026-10-31 사용자 요청: C-01 접수함에서 근로자 채팅이 왔는지 알 수 없다. 채팅이 오면 그 사례에 표시를 붙이고 맨 위로 올리고, 정렬에 채팅 시각을 더하고, 신규·진행 같은 필터 버튼 옆에 채팅 버튼을 두어 채팅이 온 사례만 모아 볼 수 있게 한다.

## 지금 화면에서 본 것
- 접수함 목록(`GET /api/center/cases`)에는 채팅 정보가 없다. 채팅은 C-02에 들어가야 사례마다 WebSocket으로 보인다
- 서버는 사례마다 역할별 읽은 자리(`history.read`, `read` 프레임, backend 28)를 이미 들고 있다. 센터가 C-02 채팅을 보면 `read.center`가 근로자 마지막 글까지 올라간다
- 정렬은 `접수 시각`·`긴급도` 두 가지이고, 신규 사례가 늘 맨 위다(FR-80)

## 범위
- 하는 것(API 모드만. 단독 모드에는 채팅이 없어 지금 화면 그대로)
  - 접수함이 보이는 동안 실제 전송 사례마다 센터 역할로 채팅 WebSocket을 하나씩 열어 둔다(`api/chat.ts`의 `useChatDigests`). `read`를 보내지 않으므로 읽음은 바뀌지 않는다. 목록에서 빠진 사례(초기화)는 닫고, 화면을 떠나면 모두 닫는다
  - 사례마다 "새 채팅 수" = 근로자 글 중 번호가 `read.center`보다 큰 것, "채팅 시각" = 근로자 마지막 글 시각
  - 새 채팅이 있는 사례: 접수 번호 옆에 `새 채팅 N` 칩(`pill.unread` + 말풍선 선 아이콘). 표 맨 위로 올리고, 그 안에서는 최근 채팅 순
  - 표에 `채팅 시각` 열(근로자 마지막 글 시각, 없으면 `—`)
  - 정렬에 `채팅 시각`(최근 채팅 순, 채팅 없는 사례는 아래에서 접수 시각 순)
  - 필터에 `채팅` 버튼(말풍선 선 아이콘, 새 채팅이 있는 사례 수 칩): 근로자 글이 하나라도 있는 사례만
  - `design.md`에 "센터 접수함" 표를 더한다
- 하지 않는 것
  - API·서버 변경(목록 응답에 채팅 필드 더하기). 실제 전송 사례가 많아지면 연결 수가 늘어나므로 `## 메모`에 남긴다
  - 소리·브라우저 알림, 머리글 메뉴 배지, KPI 칸
  - 센터 글 시각으로 정렬(채팅 시각은 근로자 글만)

## 결과
- `npm run build` → 통과(청크 크기 경고만 기존과 같다). `cd app-front && npm run build` → 통과
- API 모드(dev 5193 + 로컬 백엔드 :8000, Python 3.12 + `tzdata`, 인증 꺼짐). API로 실제 사례 두 건(C-24924 vi, C-24947 en)을 만들고, 근로자 쪽은 다른 탭에서 WebSocket으로 C-24924에 글을 보냈다
  - 첫 글: 2초 안에 C-24924가 더 늦게 접수된 C-24947 위로 올라오고, `새 채팅 1` 칩, `채팅 시각` 19:19, 필터 `채팅` 버튼에 숫자 칩 `1`(처음 `새 1`이던 것을 사용자 요청으로 숫자만으로 바꿨다)
  - 두 번째 글: `새 채팅 2`. `채팅` 필터를 누르면 C-24924 한 줄만 남는다
  - C-24924를 열어 채팅을 보고 `← 접수함`으로 돌아오니 칩과 버튼 숫자가 사라지고 C-24947이 다시 위(접수 시각 순). `채팅 시각`은 남는다
  - 정렬 `채팅 시각`: 신규 중 C-24924(채팅 있음)가 C-24947보다 위
  - 1280px·880px: 필터 줄 한 줄(38px), 표는 전처럼 `.table-wrap` 안에서만 가로 스크롤, 문서 가로 넘침 없음. 콘솔 오류는 백엔드가 뜨기 전 폴링의 502뿐
- 단독 모드(dev 5194) `/center`: 필터 `전체·신규·진행·완료`, 정렬 `접수 시각·긴급도`, 열 8개, 24행으로 지금과 같다
- 결정
  - 읽음 판단은 브라우저 저장소가 아니라 서버의 `read.center`(backend 28)를 쓴다. 다른 직원 PC에서 읽어도 같이 사라지고, 새로 고침해도 같다
  - `채팅 시각`과 맨 위 고정은 근로자 글만 센다. 센터가 답한 것은 "채팅이 왔다"가 아니다
  - 채팅 필터는 새 채팅이 아니라 근로자 글이 하나라도 있는 사례다. 새 채팅은 맨 위 고정과 칩으로 이미 보인다
  - 아이콘은 이모지가 아니라 근로자 독·시트와 같은 말풍선 선 아이콘(`.sheet-icon`)
