# 40. 증상 없이 들어오는 길: 건강보험 가입·자격과 건강검진 안내

상태: 대기
의존: 없음

## 목표
울산광역시 외국인근로자 지원센터 회신(2026-10-31, 2026년 5~10월 상담 집계)에서 센터가 꼽은 주요 의료 상담 네 유형 중 둘은 증상이 없는 사람이 묻는 것이다.
- 건강보험: 국민건강보험 가입·자격 확인, 보험료·보험급여, 직장가입자와 지역가입자 제도 안내
- 건강검진: 국가건강검진 대상 여부와 이용 방법, 검진 가능 의료기관 안내

의료 상담 329건 중 건강보험·공공의료 분야가 38건(11.6%)이다. 지금 앱은 홈의 "아파요/다쳤어요"로 증상을 넣은 뒤에야 제도 경로(S-08)로 이어지고, S-08도 "먼저 상담할 곳"만 고르는 화면이라 가입·자격·검진 질문은 들어올 길이 없다. 홈에서 바로 들어가는 고정 안내 화면을 둔다.

## 범위
- 하는 것
  - 새 화면 `/insurance`(S-14): `/guide`와 같은 고정 문구 화면. 단락 셋
    1. 가입 구분 — 직장가입자(회사가 가입하고 월급에서 보험료를 뗀다)와 지역가입자(회사 가입이 아니면 체류 조건에 따라 가입된다)의 차이, 자기가 어느 쪽인지 확인하는 법
    2. 자격·보험료 확인 — 국민건강보험공단 1577-1000, 외국인등록증을 들고 공단 지사에 가는 길, 센터에 묻는 길
    3. 국가건강검진 — 가입자·피부양자가 대상이라는 것, 대상 여부·시기·가능한 의료기관은 공단에서 확인한다는 것, 검진 결과를 가지고 진료가 필요하면 이 앱의 "아파요/다쳤어요"로 이어가는 안내
  - 단락마다 끝에 "센터에 묻기" 버튼 → `/center-request?type=policy`(제도 상담이 골라진 S-12). 하단 채팅 시트는 바꾸지 않는다
  - 홈 기능 목록에 `menuInsurance`/`menuInsuranceSub` 한 줄(`menuCoverage` 다음). `menuCoverage`는 그대로 둔다(의료비를 어디에 먼저 물을지, S-08)
  - 문구 끝에 `guideCheck`처럼 "제도는 바뀔 수 있으니 공단·센터에 확인하세요" 한 줄과 정보 기준일(`INFO_DATE`)
  - `README.md` 화면 구성 표에 S-14 `/insurance` 행, `design.md` "홈"의 기능 목록 설명
  - i18n: 새 키를 20개 언어에 넣는다(en·ko 직접, 나머지는 기계 번역 초안)
- 하지 않는 것
  - 자격·대상 여부를 판정하는 규칙(`domain/`)과 백엔드 경로. 고정 문구라 서버 몫이 없다
  - 검진 기관 검색(공단 API·카카오맵). 후속으로 남긴다
  - S-08 `/coverage`와 `/guide` 변경
