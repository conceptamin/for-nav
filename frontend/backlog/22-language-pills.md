# 22. 언어 선택 화면: 안내원 사람 아이콘, 국기 붙은 알약, 바닥 배치

상태: 완료
의존: 20 (대화형 언어 선택)

## 목표
backlog 20의 대화형 S-01을 다듬는다(2026-10-30 사용자 요청). 질문하는 안내원을 로고 대신 사람 동그라미 아이콘으로 바꿔 "누가 묻는지"를 분명히 하고, 다른 언어는 국기를 붙인 알약 버튼으로 바꿔 화면 바닥에 붙인다. 국기가 있으면 문자를 읽기 전에 자기 나라를 먼저 찾을 수 있다.

## 범위
- 하는 것
  - 안내원: `/logo.png` 대신 40px 동그라미 안 사람 모양(인라인 SVG, `--brand-2` 바탕 + `--brand`)
  - 다른 언어: 칩 → 알약(`999px`, 44px), 안에 국기 + 모국어 이름. `LANGUAGE_OPTIONS`에 `flag` 필드
  - 다른 언어 묶음과 그 아래 안내·센터 링크를 화면 바닥(119 띠 위)에 붙인다. 화면이 짧으면 지금처럼 이어서 흐른다
  - `design.md` "말풍선" 절과 둥글기 표, `README.md` S-01 설명
- 하지 않는 것
  - 대답 말풍선의 국기(요청 범위 밖. 대답은 그 언어의 문장이 이미 언어를 보여 준다)
  - 앱 바·`/my`·센터 요청의 언어 `select`에 국기
  - 국기 이미지 파일·웹폰트 추가(시스템 이모지 국기를 쓴다)

## 화면·파일
- 화면: S-01 `/`
- 수정: `src/i18n/index.ts`(`flag`), `src/pages/worker/Onboarding.tsx`, `src/styles.css`(`.w-chat .ask .avatar`, `.w-chat .chips .chip`, `.w-chat .chip .flag`, `.w-chat .chip-group`), `design.md`, `README.md`
- 새 문구 키: 없음

## 결과
- `npm run build` → 통과
- Playwright Chromium(`vite preview`), 360×780에서 폰 언어 vi-VN·ar-AE·en-US·kk-KZ → 4개 모두 scrollWidth 360(가로 넘침 없음). 첫 대답 말풍선 → `/consent`(`lang="vi"`), 알약 "Русский" → `/consent`(`lang="ru"`)
- 412×1400, vi-VN: 대답 말풍선 아래 끝 280px, 다른 언어 묶음 시작 816px, 센터 링크 아래 끝 1304px, 119 띠 시작 1328px → 바닥에 붙음
- 결정
  - "밑으로 붙으면"을 다른 언어 묶음을 화면 바닥에 붙이는 것으로 읽었다
  - 국기는 backlog 16 요청 목록 이미지를 그대로 따랐다(영어 🇺🇸, 아랍어 🇦🇪, 간체·번체 모두 🇨🇳). backlog 16의 "국기 이모지 없음" 결정은 이 요청으로 S-01 알약에 한해 바뀐다
  - 360×780에서는 알약 20개가 화면 높이를 넘어 바닥 붙임이 보이지 않고 스크롤된다. 언어가 적게 남는 경우(추천 4개)나 키 큰 폰에서 효과가 보인다
- 남은 문제: Windows 데스크톱 브라우저는 국기 이모지를 두 글자(KR 등)로 그린다. 근로자 화면은 휴대폰 대상이라 그대로 둔다
