# 38. 바닥 주 동작 버튼을 본문 맨 끝으로 내리기

상태: 완료
의존: 없음

## 목표
2026-10-31 사용자 결정: "저장하고 계속"·"보내기" 같은 주 동작 버튼이 119·채팅 독과 함께 화면 위에 떠 있을 필요가 없다. 페이지 맨 아래에 있으면 된다. 위 입력을 다 채워야 켜지는 버튼이라, 그 전에는 꺼진 채 화면 아래를 가리고 독과 두 층으로 떠서 폰에서 입력할 자리를 줄인다. 화면 위에 계속 떠 있는 것은 언제든 눌러야 하는 119·채팅 독뿐으로 둔다.

## 범위
- 하는 것
  - `.w-footer`의 `position: sticky; bottom: 0`을 뺀다. `::before` 띠 면의 기준이 되도록 `position: relative`는 남긴다
  - `.w-footer`를 쓰는 다섯 곳이 모두 바뀐다(사용자 결정: 다섯 곳 모두): S-02 동의(`Onboarding.tsx`), S-03 프로필 "저장하고 계속"(`Onboarding.tsx`), S-05 증상 입력(`Intake.tsx`), S-11 항목 선택(`Report.tsx`), S-12 센터 요청 "보내기"(`CenterRequest.tsx`)
  - `design.md`의 `.w-footer` 설명을 고친다
- 하지 않는 것
  - 띠 모양(채움·흐림·위쪽 1px 선)과 119 독 자리까지 내려오는 여백. 끝까지 내렸을 때 모양은 지금과 같다
  - 본문이 짧은 화면의 배치. `.w-screen`의 `margin-top: auto`가 그대로 화면 바닥으로 민다
  - 119·채팅 독(`.bar-119`)
