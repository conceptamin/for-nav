# 55. 채팅을 보는 근로자도 센터에 "화면에 있다"로 보이기

상태: 완료
의존: 없음

## 목표
센터 C-02는 근로자가 그 사례 통화 연결(`WS /api/center/cases/{id}/call`)에 붙어 있을 때만 "화면에 있다"로 보고 걸기 버튼을 연다(backend 16 `joined`·`peer`). 그런데 39에서 통화를 센터 채팅 시트로 옮긴 뒤 근로자 쪽 통화 연결은 시트 머리의 📞를 눌러 통화 보기로 바꿨을 때만 열린다. 그래서 근로자가 시트에서 채팅을 하고 있어도 센터에는 "근로자가 화면에 없어 걸 수 없습니다"가 뜬다(2026-10-31 사용자 보고). 시트가 그 요청의 대화를 붙여 두는 동안에는 채팅 보기에서도 통화 연결을 숨긴 채 열어 두고, 센터가 걸면 통화 보기로 시트를 연다.

## 결정 (2026-10-31 사용자)
1. 근로자 통화 연결은 시트가 그 요청의 대화를 붙여 두는 동안(채팅 보기·목록 보기·시트를 닫아 둔 동안 포함) 열어 둔다
2. 센터가 걸어 전화가 울리면 시트를 그 요청의 통화 보기로 연다

## 범위
- 하는 것
  - `CenterSheet`: 채팅 보기에서도 `CallPanel`을 숨긴 칸(`hidden`)에 붙여 둔다. 📞·💬는 보이는 칸만 바꾼다
  - `CallPanel`: 전화가 울리기 시작할 때 부르는 `onRing`을 더한다. 센터 C-02는 쓰지 않는다
  - `README.md`: C-01~C-03 행, `WS .../call` 행의 "화면에 있다" 뜻과 근로자 쪽 화면 이름
- 하지 않는 것
  - 시트를 한 번도 열지 않았거나 다른 요청을 열어 둔 근로자를 "화면에 있다"로 보이기(통화 연결은 시트가 붙여 둔 요청 하나에만 있다)
  - 서버(`backend/`) 변경, 채팅 연결로 존재를 알리는 새 계약
  - 센터 문구·통화 상태 규칙(`useCall`) 변경. 새 문구 키 없음

## 화면·파일
- 근로자 센터 채팅 시트(경로 없음), C-02
- `src/components/CenterSheet.tsx`, `src/components/CallPanel.tsx`, `README.md`

- [x] API 모드에서 근로자가 시트에서 요청 채팅만 보고 있을 때 C-02 걸기 버튼이 열리고 "근로자가 화면에 없어" 문구가 없다
- [x] 그 상태에서 센터가 걸면 근로자 시트가 통화 보기로 바뀌고 받기·거절 버튼이 보인다. 시트를 닫아 둔 상태에서 걸어도 시트가 그 요청의 통화 보기로 열린다
- [x] 근로자가 시트를 한 번도 열지 않았으면 C-02는 지금처럼 "화면에 없어"다

## 결과
- `npm run build` → 통과, `cd ../app-front && npm run build` → 통과
- 브라우저(Playwright 헤드리스 Chromium, 가짜 마이크): 이 워크트리 `backend`를 8767에, `VITE_API_BASE=/api` Vite를 5191에 띄우고 `POST /api/center/cases`로 사례를 만든 뒤 근로자(360px, en)와 센터 C-02(1280px)를 함께 열었다
  1. 근로자 창이 없을 때 C-02: "근로자가 화면에 없어 걸 수 없습니다", `전화 걸기` 막힘
  2. 근로자가 `/home`에 있고 시트를 열지 않았을 때: 같다(범위 밖, 결정 1)
  3. 근로자가 시트 채팅 목록에서 그 요청을 열어 채팅 보기(머리 `Chat with the centre`)일 때: C-02 상태 줄 없음, `전화 걸기` 열림
  4. 근로자가 시트를 ✕로 닫아 둔 동안: 3과 같다
  5. 센터가 걸면 닫혀 있던 근로자 시트가 `Call the centre` 보기로 열리고 `Answer`·`Decline`이 보인다. C-02는 "거는 중…"
  6. `Answer` → 근로자 `On a call`, 센터 `통화 중`
  7. 통화 중 근로자가 💬로 바꾸면 채팅 보기가 되고 센터는 계속 `통화 중`
- 단독 모드(`VITE_API_BASE` 없이 5192): 시트가 열리고 `.call`이 없으며 페이지 오류 없음
- 원인: 39에서 통화를 시트로 옮기며 근로자 `CallPanel`이 📞 보기에서만 붙게 됐다(`dd81784`). 그 전 S-12 전송 완료 화면은 열리면 바로 통화 연결을 붙였다

## 메모
- 통화 중에 💬로 바꾸면 이제 통화가 끊기지 않고 숨긴 채 이어진다(전에는 패널이 빠지며 끊겼다). 시트를 닫아 두는 동안 통화가 이어지던 것과 같은 규칙이다
- 통화 연결은 시트가 붙여 둔 요청 하나뿐이다. 앱 어디에 있든 모든 내 요청에 존재를 알리려면 `WorkerLayout`에서 요청마다 연결을 두거나 서버가 채팅 연결(`ChatHub.has_worker`)을 통화 존재에 합쳐야 한다. 후자는 서버 계약 변경이라 backend 항목이다
