# 32. 하단 119·센터 채팅을 유리 독 하나로 다시 그리기

상태: 완료
의존: 30 (하단 버튼 글래스), 31 (한쪽에 모아 띄우기)

## 목표
2026-10-31 사용자 요청: "119랑 채팅 아이콘이 좀 촌스러워. 너가 생각했을때 세련된 디자인으로 변경해줘." 따로 떠 있던 두 버튼(📞 이모지·진한 그러데이션·글자 그림자의 빨간 알약, 틸 유리 알약)을 떠 있는 유리 독(알약) 하나에 담아, 효과를 줄이고 정돈된 모양으로 바꾼다.

## 범위
- 하는 것
  - `WorkerLayout`: `.bar-119` 안에 `.bar-dock`을 두고 119와 채팅을 담는다. 📞 이모지 대신 직접 그린 전화기 외곽선 SVG(32px 원 안), 채팅 아이콘은 둥근 말풍선 + 점 셋으로 다시 그린다. 쓰지 않게 된 `with-chat` 클래스를 뺀다
  - `styles.css`
    - `.bar-dock`: 999px, `--card` + 흐림 + `--glass`, 안쪽 4px, 높이 52px
    - 119: 불투명한 빨강(`--danger-top` → `--danger`), `--glass-color-flat`, 흐림·바깥 그림자·글자 그림자 없음. 문구 `--t4` 굵게
    - 채팅: 56×44px 평평한 투명 면 + 틸 아이콘. 지금 화면·누름은 `--brand-2` + `--glass-in`
    - `--bar-119` 64px → 72px(독이 52px). `.w-main` 아래 여백과 `.w-footer` 자리는 이 변수를 따라간다
    - backlog 30의 토큰(`--danger-glass*`, `--glass-sheen*`, `--glass-lift`, `--glass-color-lift`, `--card-tint`)을 지우고 `--danger-top`, `--glass-color-flat`을 더한다
  - `design.md`: 색이 있는 면 규칙(119 반투명 예외 삭제), 고정 띠, 바탕 표, 둥글기 표, 그림자 토큰
- 하지 않는 것
  - 문구·동작·자리(끝 쪽, backlog 31) 변경
  - 애니메이션, 색이 있는 빛(glow) 그림자

- 파일: `src/components/WorkerLayout.tsx`, `src/styles.css`, `design.md`

## 결과
- `cd frontend && npm run build` → 통과, `cd app-front && npm run build` → 통과
- 브라우저(dev 서버 5180, 데모 로그인 상태)
  - 375px `/home` ko: 오른쪽 끝 유리 독 안에 빨간 119(전화기 원 + `응급 상황이면 119`)와 틸 말풍선
  - 360px `/home` uz: 독 16~344px, 높이 52px, 119 두 줄 44px 안
  - 360px `/center-chat` ar: 독 16~288px(왼쪽), 채팅이 왼쪽 가장자리, 지금 화면이라 `--brand-2`
  - 360px `/intake` ko: 바닥 버튼 띠 아래 끝 708px, 독 위 718px(10px 간격)
  - 360px `/signup`(로그인 전): 119 혼자 든 독이 오른쪽 끝(164~344px)
  - 콘솔 오류 없음
- 결정
  - 두 버튼을 각각 띄우지 않고 독 하나에 담았다. 떠 있는 면이 하나라 그림자·빛 반사가 겹치지 않고 깔끔하다
  - 119를 불투명한 빨강으로 되돌렸다. 유리 독이 "유리"를 맡으므로 빨강까지 비칠 필요가 없고, 대비 예외도 없어진다
  - 이모지를 쓰지 않는다. 기기마다 모양이 달라 정돈된 느낌을 깬다. 아이콘은 모두 외곽선 SVG로 맞췄다(앱 바 번역 아이콘과 같은 결)
