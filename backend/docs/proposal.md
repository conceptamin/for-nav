# for-nav 백엔드 기획서

작성일: 2026-10-21 · 기준 문서: 울산 외국인 근로자 산업보건 내비게이터 기획안(보완판 2)

## 1. 목적과 경계

근로자의 모국어 입력을 받아 응급 여부, 작업 맥락, 먼저 상담할 비용 경로, 진료과, 지금 열린 곳, 의사용 한국어 요약을 돌려준다. 판단이 필요한 곳은 규칙, 이해와 설명은 LLM, 안전이 걸린 응급 감지는 직접 학습한 모델이 맡는다.

- [공통 API 계약](../../docs/api-contract.md)
- [프론트 기획서](../../frontend/docs/proposal.md)
- [모델링 기획서](../../modeling/docs/proposal.md)

하지 않는 일: 진단, 산재 판정, 작업 관련성 분류, 체류 자격 확인, 개인 식별 정보 수집, 증상 저장, 약 정보 설명(약봉투 OCR 제외).

## 2. 처리 흐름

```text
POST /triage
  텍스트 ─┬─> 응급 키워드 규칙 ─┐
          ├─> 응급 감지 모델 ───┼─ OR ─> emergency
          └─> LLM 맥락 추출 ────┴──────> context, missing_fields
                                   └──> 진료과 대응 표 ─> department

POST /route    Q1~Q3 ─> 결정 표 ─> route, message, contacts
POST /summary  context + include + consent ─> (뺀 항목 제거) ─> LLM ─> summary_ko
GET  /guide    정적 콘텐츠 (언어별)
GET  /hospitals at, day, district, department ─> mock 또는 공공 API
```

응급 규칙과 모델은 LLM보다 먼저, LLM과 독립적으로 실행한다. LLM이 느리거나 실패해도 응급 결과는 나간다.

## 3. 모듈

| 모듈 | 책임 |
|---|---|
| `api/` | 라우터, 요청·응답 Pydantic 모델(계약의 원본) |
| `emergency/` | 키워드 규칙(언어별 표현 목록), 모델 불러오기·추론, OR 결합 |
| `extraction/` | LLM 프롬프트와 구조화 출력 검증, 빈 항목 계산 |
| `routing/` | 비용 경로 결정 표, 언어별 안내 문구, 연결 기관 |
| `departments/` | 증상·부위 → 진료과 대응 표 |
| `summary/` | 항목 필터, LLM 요약 생성 |
| `llm/` | LLM 클라이언트 인터페이스, 실제 구현, 테스트용 가짜 구현 |
| `content/` | 산재 안내·연락처·병원 mock 데이터(정보 기준일 포함) |

규칙 모듈(`routing/`, `departments/`, `emergency/`의 규칙 부분)은 FastAPI·LLM을 import하지 않는 순수 함수로 둔다.

## 4. LLM 사용

- 맡기는 일: 작업 맥락 추출(증상, 부위, 시작 시점, 작업 유형, 보호구, 사고 상황), 의사용 한국어 요약. 그 외에는 쓰지 않는다.
- 개발은 무료 등급 API로 하고, 데모에는 합성 데이터만 넣는다. 무료 등급은 입력 데이터 처리 정책이 유료와 다를 수 있으므로 사용 전 약관을 확인하고 phase 문서에 기록한다.
- 노트북에서 돌아가는 공개 LLM(로컬 실행)을 예비로 시험한다. 인터페이스는 같다.
- 출력은 계약 스키마로 검증한다. 스키마에 맞지 않으면 한 번 재시도하고, 그래도 실패하면 `LLM_UNAVAILABLE`로 처리한다. 추출 결과에 없는 값을 채워 넣지 않는다.
- 호출에는 시간 제한을 둔다. 값은 phase 문서에서 정한다.

## 5. 비용 경로 규칙

결정 표는 계약 4장이 기준이다. 일과 관련되면 항상 산재 상담이 먼저다(산재가 인정되면 산재보험이 치료비를 부담). Q2 "잘 모르겠어요"와 Q3 "아니요"는 지원센터 상담으로 보낸다. 입원·수술 필요 여부는 다친 직후에 알 수 없으므로 묻지 않고, 울산 의료비 지원 결과에서 조건으로 안내한다.

| 경로 | 안내 요지 | 연결 기관 |
|---|---|---|
| 산재 상담 | 산재보험으로 치료비를 받을 수 있고 사업주가 돕지 않아도 직접 신청 가능. 진료 기록·영수증·근무 기록 보관 | 근로복지공단 울산지사, 고용노동부 상담 1350, 외국인근로자지원센터 |
| 건강보험 일반 진료 | 가까운 의원에서 건강보험으로 진료 | "지금 갈 수 있는 곳" 화면 |
| 울산 의료비 지원 | 입원·수술이 필요하면 상담. 본인 부담 약 10%, 외래는 지원되지 않을 수 있음 | 대한적십자사 울산지사, 참여 병원, 외국인근로자지원센터 |
| 지원센터 상담 | 울산외국인근로자지원센터 상담, 건강보험 가입 여부도 함께 확인 | 지원센터 |

근거(보완판 2 기준): 울산 의료비 지원은 2024-07-30 협약으로 건강보험 미적용 외국인, 울산 거주·근무 90일 이상, 국내 발병, 입원·수술비를 울산시 70%·의료기관 20%·본인 10% 부담. 2026년 운영 여부와 세부 조건은 미확인이며 [계약 8장](../../docs/api-contract.md)의 미결 표로 관리한다.

## 6. 개인정보와 보안

- 서버 미저장: DB·파일 쓰기 없음. 메모리에서 처리하고 응답 후 버린다.
- 로그: 경로, 상태 코드, 소요 시간, `request_id`만. 예외 로그에도 요청 본문을 넣지 않는다.
- 외부 전송: 맥락 추출과 요약 카드만 외부 LLM으로 간다. 프론트가 처음 쓸 때 고지·동의를 받는다. 실서비스는 로컬·온디바이스 처리로 전환한다.
- 배포 주체는 사업주가 아니라 지자체·외국인근로자지원센터를 전제로 한다.

## 8. 측정

성능 목표와 측정 방법은 [모델링 기획서](../../modeling/docs/proposal.md)의 지표 표를 따른다. 백엔드가 직접 맡는 지표는 비용 경로 안내 정확도(가상 사례 30개, 목표 예시 90% 이상)와 작업 맥락 추출 정확도(항목별, 목표 예시 90% 이상)다. 목표치는 예시이며 측정 전 달성을 적지 않는다.
