# 13. 진료과 모델 B 개선(평가셋 확대 → 표 보강 → 모델 정리, v3)

상태: 대기
의존: 07, 08

## 목표
모델 B(07)의 안내 조합 검증 적중률은 표 분포를 그대로 답으로 쓴 값과 같아, 모델 구조만 바꿔서는 오르지 않는다(아래 메모의 진단). 개선을 잴 수 있게 진료과 평가셋을 먼저 키우고, 표의 라벨·빈 조합·여러 개 선택 입력을 보강한 뒤 모델을 정리해 `dept_b/v3`로 기록한다. 앙상블(08)은 바뀐 모델 B로 다시 조정한다.

## 범위
- 하는 것(순서대로. 단계마다 결과를 적고 다음 단계로 간다)
  1. **평가셋 확대**: `department_guide.csv`에 안내 조합을 더한다. 후보는 05 메모의 서울아산병원 11개(사전협의 후)와 다른 병원 공개 안내. 사람이 검토해 `reviewed=yes`로 바꾼다. 60건 이상이 되면 조정용과 최종 평가용으로 나눌지 사용자와 정한다(지금은 진료과 모델에 따로 남겨 둔 테스트셋이 없다, 07 메모)
  2. **표 성능을 반복 교차검증으로 잰다**: 조합 단위 5겹 × seed 여러 개로 KL·표 1순위 대비 Top-k의 평균과 편차를 적는다. 이후 변경은 이 편차를 넘을 때만 개선으로 본다
  3. **외상 라벨 보정 규칙**(사용자 승인 필요): HIRA는 상병 기준이라 외상 조합이 피부과·정형외과로 쏠린다. 병원 안내 원칙에서 보정 규칙을 정하고, 보정한 행은 `source`에 표시한다. 검증 조합의 오답을 보고 행을 고치지 않는다
  4. **빈 조합 채우기**: 온몸 외상, 귀·코 외상(`ent-*-yes`), 화상(손상 없음) 등 표에 없는 조합을 HIRA에서 더 찾고, 없으면 `llm-draft`로 넣는다. `llm-draft`는 05 규칙대로 학습 라벨로만 쓴다
  5. **여러 개 선택 행 합성**: 표의 단일 조합 분포를 섞어 부위·증상 두 개 선택 행을 만든다. 섞는 방식(평균·곱 후 정규화)은 2의 교차검증으로 고른다
  6. **비교 기준선과 모델 정리**: 다항 로지스틱 회귀, 표 조회 + 백오프(표에 없으면 부위 평균·증상 평균)를 같은 셋으로 잰다. MLP 하이퍼파라미터는 에폭 확인 간격 25 → 5, L2 {1e-3 … 1e-1}, 은닉 {8, 16, 32}로 넓히고, 고정한 seed 목록 5개의 평균 예측을 검토한다(결정성 유지)
  7. **v3 기록과 앙상블 재조정**: `scripts/train_dept_b.py --round v3`, 08과 같은 방식으로 A:B 가중치·폴백 기준값을 다시 고르고, test는 v3에서 한 번만 평가한다
- 하지 않는 것
  - 진료과 10종·입력 피처 변경(설계 원칙), `backend/` 수정
  - 검증 조합 결과를 보고 표 행을 고치는 것, test 오류 분석
  - PyTorch 등 새 학습 의존성(07에서 numpy로 정함)
