# 14. 센터 상담 자료(비공개)로 어휘 범위 점검

상태: 대기
의존: 없음

## 목표
울산광역시 외국인근로자 지원센터가 2026년 5~10월 의료 상담 329건을 성명·전화번호·직업·담당자명을 지우고 상담 내용의 개인정보를 일부 마스킹해 제공한다(회신 5항, 2026-10-31). 조건은 **연구·서비스 설계 목적 한정, 제3자 제공·외부 공개는 센터와 사전 협의**다. 이 자료로 둘을 점검한다.
1. 앱의 부위·증상 열거값(`frontend/src/domain/vocab.ts`)이 실제 상담 내용을 얼마나 덮는지
2. 상담의 분야·국적·월 분포가 mock·통계 설계(frontend 42)와 맞는지

결과는 분자·분모 집계만 남긴다. 상담 원문은 어디에도 옮기지 않는다.

## 범위
- 하는 것
  - 보관: 받은 파일을 `data/raw/ulsan_center/`에 그대로 둔다(`.gitignore`의 `data/raw/*`로 이미 git 제외). 가공본도 `data/processed/ulsan_center/`(git 제외)에만 둔다. `download_data.py`에는 넣지 않는다(내려받는 자료가 아니다)
  - `data/README.md` 요약 표에 행 추가: 출처 울산광역시 외국인근로자 지원센터, 라이선스 칸에 "비공개. 연구·서비스 설계 한정, 제3자 제공·외부 공개는 센터 협의", 학습·평가 사용 칸에 "학습 불가, 로컬 점검만". 아래 절에 열 목록·행 수·마스킹 상태를 적고, 파일 이름·해시·원문 예시는 적지 않는다
  - `scripts/check_center_coverage.py`: 상담 내용(한국어 상담 기록)에서 부위·증상 한국어 표기를 찾아 분야별로 "하나 이상 맞은 건수 / 전체"를 센다. 월·분야·국적 분포를 센다. 출력은 `reports/center_coverage_v0.{json,md}`로, 집계 수치만 담고 5건 미만 칸은 `<5`로 가린다
  - 미매칭 상담은 사람이 읽고 **어휘 후보 단어 목록**(예: "허리", "두드러기")만 `## 결과`에 적는다. 어느 상담에서 나왔는지, 몇 건인지는 적지 않는다
  - 후보 어휘는 `frontend/backlog/`의 새 항목이나 기존 항목 `## 메모`로 넘긴다(열거값 변경은 프론트·백엔드·모델링을 함께 바꾸므로 사용자에게 묻는다)
- 하지 않는 것
  - 자료를 LLM API(Anthropic 등)나 외부 서비스에 보내는 평가·추출·번역. 제3자 제공이라 센터 협의 전에는 하지 않는다
  - 모델 학습·검증 데이터로 쓰기. 라벨이 없고 건수가 적고, 조건상 학습에 쓸 수 없다
  - 원문·마스킹 텍스트를 저장소, 리포트, 노트북 출력, mock 문장, 프롬프트 예시, 테스트 픽스처에 넣기. 노트북으로 본 경우 출력을 지운 뒤 커밋한다
  - 센터 비의료 상담(2,230건)은 받지도 다루지도 않는다

## 입력·출력
- 입력: `data/raw/ulsan_center/`(비공개, 로컬에만)
- 출력: `reports/center_coverage_v0.{json,md}`(집계만), `data/README.md` 행, `scripts/check_center_coverage.py`

## 완료 기준
- [ ] `git status`와 `git diff --cached`에 `data/raw/ulsan_center/`·`data/processed/ulsan_center/` 파일이 없다
- [ ] `reports/center_coverage_v0.md`를 사람이 읽어 상담 원문 구절·이름·연락처·날짜(월 단위 밖)가 없다. 모든 수치가 분자 / 분모이고 5건 미만은 `<5`
- [ ] 분야별(의료·보건 / 건강보험·공공의료 / 의료비 지원) 어휘 매칭률, 월별·국적별 분포가 적혀 있다
- [ ] 자료가 없는 환경(CI)에서 `uv run pytest`가 그대로 통과한다(스크립트는 자료가 없으면 안내 한 줄만 내고 끝난다)
- [ ] `uv run ruff check . && uv run ruff format --check .` 통과

## 메모
- 응급 키워드 범위 점검은 뺐다. 앱이 응급 여부를 판정하지 않기로 해서 응급 키워드가 없어졌다(modeling 15, frontend 43, backend 26)
- 센터 회신 수치: 전체 상담 2,559건 중 의료 329건(12.9%). 분야 의료·보건 288(87.5%) / 건강보험·공공의료 38(11.6%) / 의료비 지원 3(0.9%). 월별 16·25·41·85·97·65. 국적 12개국, 상위 5개국(인도네시아·러시아·카자흐스탄·스리랑카·필리핀) 287건(87.2%)
- 센터 통계는 센터 접수 건수라 울산 전체 외국인근로자의 의료 이용 현황이 아니다(회신 1항). 리포트 머리에 같은 말을 둔다
- 상담 기록이 한국어라 외국어 자유 입력 추출(`/api/extract`)의 평가는 이 자료로 할 수 없다. 외국어 평가 세트는 따로 만든다
- 자료를 외부(LLM 포함)에 쓸 필요가 생기면 먼저 센터와 협의하고, 합의 내용을 `data/README.md`에 적은 뒤 새 항목으로 한다
